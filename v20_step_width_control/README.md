# V20 — 步宽控制探索

**状态**：初步实现，未达标（基础架构完成，控制律调优未完成）
**日期**：2026-06-03
**定位**：V19 后的 3D 侧向稳定增强尝试。**准被动**（矢状面 FSM + 冠状面主动步宽规划），不是纯被动。

## 1. 设计动机

V18 和 V19 的否定结果明确指出：
- **V18**：3D 侧向被动稳定不存在（roll_k<200 发散，roll_k≥500 等效 2D）
- **V19**：髋外展主动稳定不充分（最佳 7 alt/2.97s，侧向漂移率 0.05-0.10 m/step 是修正能力的 5-10 倍）

V19 揭示的物理限制：髋外展关节扭矩只能产生躯干倾斜，但无法产生 net 侧向地面反力。真正改变侧向位置需要**脚底位移**。

V20 的目标：通过**步宽控制（Step-Width Control）**主动规划摆动腿的侧向落脚位置，改变支撑多边形来实现 3D 侧向稳定。

## 2. 技术架构

### 已完成部分

1. **3D 模型**（`model_3d_v20.py`）
   - 继承 V19 的 10-DOF 模型（hip_x/y/z, hip_roll, left/right hip/knee/abd, 被动 ankle）
   - 新增参数：`step_width_kp`, `step_width_kd`, `step_width_nominal`, `step_width_max_deviation`

2. **步宽规划器**（`step_width_planner.py`）
   - `StepWidthPlanner` 类：实现 LIPM 反馈律 `y_foot = y_hip + k_p*y_hip + k_d*vy_hip + y_nominal`
   - `solve_3d_ik()` 函数：3D 逆运动学求解（给定落脚点计算 hip/knee/abd 角度）
   - `interpolate_y_trajectory()` 函数：摆动相侧向轨迹平滑插值

3. **仿真框架**（`simulate_v20.py`）
   - 主循环集成矢状面 V10 PD 控制 + 冠状面步宽规划接口
   - 接触检测、步态事件记录、失败分类
   - CSV 数据导出（hip_y, vy, abd 角度, 步宽目标等）

### 未完成部分

1. **控制律集成**：步宽规划器与实际控制的耦合未完全实现
   - 当前实现退化为 V19 风格的髋外展 PD（未使用步宽轨迹）
   - 3D IK 求解的数值稳定性未充分测试
   - 摆动相轨迹跟踪与矢状面 FSM 的时序同步未验证

2. **参数调优**：未完成 k_p/k_d 网格扫描
   - Smoke Test（k_p=k_d=0 开环）失败：~1s 后跌倒
   - 原因：基础控制架构尚未稳定，无法进入参数优化阶段

## 4. 问题分析

### 根本原因

1. **控制复杂度低估**：步宽控制需要精确的 3D IK + 轨迹规划 + 时序同步，比预期复杂
2. **基线不稳定**：V19 本身就不稳定（~7 alternations），V20 需要在此基础上改进困难
3. **调试时间不足**：参数空间大（k_p, k_d, abd_kp, abd_kd, timing），系统化调优需要大量实验

### 技术债务

- 3D IK 求解器的简化假设（abd 角度 ≈ atan2(dy, hypot(dx,dz))）可能引入误差
- 摆动相开始时刻的检测（u < 0.05）过于简单，可能导致目标更新延迟
- 步宽轨迹与矢状面摆动轨迹的耦合未考虑（改变 y 位置会影响腿长，进而影响矢状面 IK）

## 5. 决策门判定

**判定**：**V20 不通过，3D 化路线建议暂停**

### 理由

1. **技术可行性存疑**：V18（被动）+ V19（髋外展）+ V20（步宽控制）三次尝试均未达标
2. **投入产出比低**：继续 3D 化需要更激进的主动策略（脚踝 roll/yaw, 质心轨迹规划），远离"准被动"定位
3. **2D 主线已成熟**：V13.7（摩擦补偿）+ V17（状态估计）提供了稳定且充分验证的 2D 控制基线

### 建议路径

**跳过 V21，直接进入 V22 硬件设计**：
- 基于 V13.7 + V17 的 2D 样机（矢状面行走 + 侧向被动约束或外部支撑）
- 降低风险，快速验证仿真到实物的迁移
- 3D 问题可在硬件平台上迭代（实测数据 > 仿真调参）

## 10. 经验教训

1. **渐进式验证**：应先在 2D 上验证步宽控制概念（简化为"步长控制"），再扩展到 3D
2. **基线稳定性优先**：V19 本身不稳定时，在其基础上迭代改进困难
3. **时间盒管理**：复杂任务应设置时间上限，未达标时及时止损并记录

## 11. 与 ROADMAP 决策门的关系

V20 对应 ROADMAP 中"V21 之后的决策门"：

> V21 之后：如果 3D 纯被动不收敛，降级为"矢状面被动 + 冠状面主动稳定"的准被动路线。**V18+V19 已确认此降级必要**：被动侧向稳定不存在，髋外展单独不足，需步宽调制或足部侧向位移。

V20 尝试了"步宽调制"路线但未验证成功。综合 V18/V19/V20 三个版本的否定结果，**建议放弃 3D 化（V21），直接进入 V22 硬件设计**（基于 2D 主线）。

3D 行走可作为未来工作，在硬件平台上用实测数据驱动算法设计，而不是继续在仿真中调参。
