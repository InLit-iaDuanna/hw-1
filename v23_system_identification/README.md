## 1. 概述

V23 的目标是从实际硬件采集的数据中辨识系统物理参数，包括摩擦系数、转动惯量、弹簧刚度、阻尼等，用于修正仿真模型或调整控制器。

## 2. 辨识方法

### 2.1 摩擦系数辨识（最小二乘法）

**原理**：电机恒速转动时，驱动扭矩 = 库仑摩擦 + 粘滞摩擦

```
τ = τ_C * sign(ω) + b * ω
```

**实验步骤**：
1. 关节悬空，无负载
2. 指令电机以不同速度恒速转动（ω = 0.1, 0.2, ..., 1.0 rad/s）
3. 记录稳态扭矩 τ
4. 线性回归求解 τ_C 和 b

**数据采集**：10 组速度 × 5 秒 = 50 秒

### 2.2 转动惯量辨识（自由摆动）

**原理**：关节自由摆动，角加速度与转矩成正比

```
τ = J * α + b * ω + τ_C * sign(ω)
```

**实验步骤**：
1. 抬起腿至 45°，释放自由摆动
2. 记录角度 θ(t) 和角速度 ω(t)
3. 数值微分得角加速度 α(t)
4. 已知 τ_C 和 b（上一步），求解 J

### 2.3 弹簧刚度辨识（静态加载）

**原理**：弹簧扭矩 = 刚度 × 角度偏移

```
τ_spring = k * (θ - θ_0)
```

**实验步骤**：
1. 踝关节：悬挂已知质量，测量偏转角
2. 膝关节：同上
3. 计算 k = mg * L / Δθ
