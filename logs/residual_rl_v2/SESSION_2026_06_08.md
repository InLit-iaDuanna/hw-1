## 🔧 Technical Details

### Environment Architecture

**V13.7 FSM Controller (1kHz inner loop)**:
- Phase-based control with energy regulation
- Friction compensation feedforward
- L1 motor model with saturation
- Event-driven support foot switching

**PPO Residual Layer (200Hz outer loop)**:
- Observes: 42-dim state (20 base + 22 FSM/phase info)
- Acts: 2-dim hip-only residual (±0.05 N·m initial scale)
- Reward: Baseline-relative improvement

### Critical Code Pattern

```python
def step(self, action):
    # ✅ MUST use discrete step count for time
    t = self.steps * self.dt  # NOT self.sim_time!
    
    # V13.6 FSM control
    tau = control_v136(fsm, self.data, t, self.support_foot, self.burst_start_t, E_current)
    
    # Friction compensation
    if self.params.compensate_friction:
        tau = [_compensate(tau[i], qvel[i], motor) for i in range(4)]
    
    # L1 motor model
    tau_out = [actuator.compute_actual_torque(tau[i], qvel[i])[0] for i in range(4)]
    
    # Apply control
    self.data.ctrl[:] = tau_out
    mujoco.mj_step(self.model, self.data)
    
    # FSM state update (AFTER physics step)
    self._update_fsm_state()
    
    self.steps += 1
```

### Observation Space (42 dimensions)

**Base (20)**:
- Joint angles: 6 (left_hip, left_knee, left_ankle, right_hip, right_knee, right_ankle)
- Joint velocities: 6
- Hip position: 2 (x, z)
- Hip velocity: 2 (vx, vz)
- Foot contacts: 4 (left_heel, left_toe, right_heel, right_toe)

**Extended (22)**:
- Left phase one-hot: 4 (stance_early, stance_late, swing_thrust, swing_retract)
- Right phase one-hot: 4
- Support foot: 2 (left, right)
- Time since contact: 1 (normalized)
- Time since burst: 1 (normalized)
- Energy current & delta: 2
- V13.7 base torques: 4 (normalized by 4.0 N·m)
- Last residuals: 4 (normalized by residual_scale)

### Action Space (2 dimensions)

```python
action_space = Box(low=-1.0, high=1.0, shape=(2,))

# Map to 4-dim residual
residual[0] = residual_scale * action[0]  # left_hip
residual[1] = 0.0                         # left_knee (fixed)
residual[2] = residual_scale * action[1]  # right_hip
residual[3] = 0.0                         # right_knee (fixed)
```

### Reward Function

```python
# Per-step reward
dx_ref = 0.000386  # baseline velocity per step
reward = (
    50.0 * (dx - dx_ref)              # Forward improvement
    - 0.02 * np.sum(residual ** 2)    # Residual cost
    - 0.01 * np.sum((residual - prev_residual) ** 2)  # Smoothness
    - 0.02 * positive_work            # Energy cost
)

# Terminal bonuses
if truncated:  # Successful completion
    reward += 100.0 * (total_distance - expected_distance)
if terminated:  # Failure
    reward -= 50.0
```

## 🎓 Lessons Learned

### 1. Time Parameter Sensitivity
Control systems with event-driven state machines are extremely sensitive to time parameter consistency. A difference of `steps * dt` vs accumulated `sim_time` causes divergence after ~1.3s.

### 2. Identity Testing is Essential
Before adding complexity (42-dim obs, residual actions), validate that the base control loop can reproduce the baseline. The simplified version saved hours of debugging.

### 3. Debugging Methodology
- ✅ Start with FSM event counting
- ✅ Track contact states over time
- ✅ Compare side-by-side with known-good implementation
- ✅ Create minimal reproduction case
- ❌ Don't assume code is "close enough" without validation

### 4. Batch Processing is Not Always the Problem
When inner_steps=1 still failed, it confirmed the issue was in the control computation itself, not the batching structure.

### 5. Subagent Limitations
Complex debugging tasks with subtle timing bugs may require human oversight. The subagent created a comprehensive implementation but introduced a critical bug that took 1.5 hours of manual debugging to find.
