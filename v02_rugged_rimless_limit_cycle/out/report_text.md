# V3 无轮辐被动极限环证明说明

V3 采用经典 rimless wheel 模型来说明被动动态步态的核心机理。模型没有电机和主动控制器，系统在斜坡上运动时，一步之内由重力势能转化为动能，脚端碰撞时损失一部分能量。当重力补能和碰撞损失达到平衡后，步间状态会收敛到稳定的周期运动。

当前 MuJoCo 回放使用真实重力 `0 0 -9.81` 和倾斜平面驱动轮辐下坡运动，不使用匀速预设动画。轮子沿斜坡向前滚落，角速度随重力和碰撞变化。

将每次碰撞后的角速度记为 `omega_k`，可以得到步间 Poincare 映射：

`omega_{k+1} = cos(2 alpha) * sqrt(omega_k^2 + 2g/l * (1 - cos(2 alpha)) * sin(gamma))`

其中 `alpha` 是相邻辐条半角，`gamma` 是斜坡角，`l` 是腿长。仿真输出的 Poincare 点逐步收敛到固定点 `omega*`，相图形成重复轨道，说明系统形成了稳定被动极限环。

V3 的作用是提供数学和动力学证明；V4/V5 则把这个机理转成更接近双腿步态的可视化形式。
