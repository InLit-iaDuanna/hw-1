# Parameter Tuner 使用指南

## 启动应用

### 方法 1: 使用启动脚本（推荐）

```powershell
cd D:\Dunna\Documents\hw-1
.\parameter_tuner\run_tuner.ps1
```

```powershell

```

启动后，浏览器会自动打开 http://localhost:8501

## 使用流程

### 1. 选择版本

- 在侧边栏选择要调优的版本
- 默认选择 V13.7 (FSM + 摩擦补偿)
- 支持版本: V10, V13.6, V13.7, V14, V16, V17

### 2. 编辑参数

进入左侧导航 → "参数编辑器"

#### 机械参数
- 髋部质量、躯干质量
- 大腿长度、小腿长度
- 足底半径、足底长度

#### 控制参数
- 髋关节 Kp/Kd (比例/微分增益)
- 膝关节 Kp/Kd
- 力矩限制

#### 电机参数 (V13.7/V16/V17)
- 电机预设选择: MX-64AR / Maxon EC-i / 理想电机
- 摩擦补偿开关 (V13.7/V17)

#### 仿真设置
- 仿真时长 (duration)
- 时间步长 (timestep)
- 初始速度

### 3. 运行仿真

进入左侧导航 → "仿真运行器"

1. 配置仿真:
   - 结果文件前缀 (自动生成带时间戳)
   - 采样频率 (默认 160 Hz)

2. 查看参数摘要

3. 点击 "运行仿真" 按钮

4. 观察进度:
   - 进度条显示估计进度
   - 勾选 "显示详细日志" 查看实时输出

5. 仿真完成后:
   - 显示状态、时间、前进距离
   - 结果自动保存到 `vXX_*/out/` 目录

### 4. 查看结果

进入左侧导航 → "结果可视化"

#### 轨迹图
- 髋部 X-Z 平面轨迹
- 速度时间曲线 (前向/垂直)
- 髋部高度变化

#### 关节角度
- 髋关节/膝关节角度曲线
- 相位平面图 (角度 vs 角速度)

#### 能量分析
- 机械能变化
- 累积输入能量
- 能量效率

#### 统计信息
- 仿真时长、前进距离、平均速度
- 着地次数
- 关键参数统计表

### 5. 保存配置

在 "参数编辑器" → "导入/导出" 选项卡:

- **导出**: 点击 "下载 YAML" 保存当前参数
- **导入**: 上传 YAML 文件加载历史配置

## 快捷操作

### 查看历史运行

在 "仿真运行器" 页面底部:
- 显示最近 10 次运行
- 点击 📊 按钮加载历史结果到可视化器

### 导出数据

在 "结果可视化" 页面底部:
- 下载完整 CSV 数据
- 下载统计摘要

## 典型工作流

### 场景 1: 调试新参数

1. 选择版本 (V13.7)
2. 在参数编辑器调整参数
3. 设置 duration=5.0 快速测试
4. 运行仿真
5. 查看结果，判断是否稳定
6. 迭代调整

### 场景 2: 对比不同配置

1. 运行配置 A，记录结果
2. 修改参数得到配置 B
3. 运行配置 B
4. 在历史记录中对比两次运行

### 场景 3: 参数扫描

对于系统性的参数空间探索，推荐使用原始 `scan_*.py` 脚本:
- `v10_rolling_foot_biomimetic_gait/scan_rolling_foot_params_v10.py`
- `v13_7_friction_compensation/scan_v13_7_tauC_verify.py`

Tuner 更适合交互式单点调试。

## 注意事项

1. **参数范围**: 滑块限制了合理范围，超出可能导致仿真失败
2. **仿真时长**: 长时间仿真 (>20s) 会增加等待时间
3. **结果文件**: 保存在各版本的 `out/` 目录，定期清理
4. **电机模型**: V13.7/V16/V17 才支持电机参数调整
5. **摩擦补偿**: 仅 V13.7/V17 支持

## 故障排除

### 仿真失败

**症状**: 进程退出码非 0

**可能原因**:
- 参数超出物理合理范围
- 电机力矩不足导致倾倒
- 数值不稳定

**解决**:
1. 勾选 "显示详细日志" 查看错误
2. 重置为默认参数测试
3. 逐步调整单个参数

### 图表不显示

**症状**: "Plotly 未安装" 警告

**解决**:
```powershell
.\.venv-mujoco\Scripts\python.exe -m pip install plotly
```

### 页面无响应

**症状**: Streamlit 卡住

**解决**:
1. 按 Ctrl+C 停止服务器
2. 重新运行 `run_tuner.ps1`
3. 刷新浏览器

## 进阶技巧

### 自定义参数范围

编辑 `version_adapter.py` 中的 `get_param_specs()`:

```python
"hip_kp": {
    "label": "髋关节 Kp",
    "min": 5.0,      # 修改最小值
    "max": 100.0,    # 修改最大值
    "step": 2.0,     # 修改步长
}
```

### 添加新版本支持

参考 `version_adapter.py` 中的 `V137Adapter` 类，实现新的适配器。

### 批量运行

使用 Python 脚本调用仿真函数:

```python
from v13_7_friction_compensation.simulate_v13_7 import run_simulation_v137, V137Params
params = V137Params()
result = run_simulation_v137(params, save_prefix="batch_01")
```
