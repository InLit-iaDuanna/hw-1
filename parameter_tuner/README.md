# Parameter Tuner - HW-1 步态仿真参数调优工具

基于 Streamlit 的交互式参数调优工具，支持实时调整参数、运行仿真、可视化结果。

## 功能特性

- **多版本支持**: V10, V13.6, V13.7, V14, V16, V17
- **参数编辑**: 可视化滑块调整机械参数、控制增益、电机参数
- **实时仿真**: 一键运行仿真，显示实时进度
- **结果可视化**: 轨迹图、关节角度、能量分析、相位平面
- **参数管理**: 导入/导出 YAML 配置
- **历史记录**: 查看历史运行结果

## 快速开始

### 1. 安装依赖

```powershell
# 在 .venv-mujoco 环境中安装
.\.venv-mujoco\Scripts\python.exe -m pip install -r parameter_tuner\requirements.txt
```

### 2. 启动应用

```powershell
# 使用启动脚本（推荐）
.\parameter_tuner\run_tuner.ps1

# 或手动启动
.\.venv-mujoco\Scripts\streamlit.exe run parameter_tuner\app.py
```

### 3. 使用流程

1. **选择版本**: 在侧边栏选择要调优的版本（默认 V13.7）
2. **编辑参数**: 进入"参数编辑器"，使用滑块调整参数
3. **运行仿真**: 进入"仿真运行器"，点击"运行仿真"按钮
4. **查看结果**: 进入"结果可视化"，查看轨迹、角度、能量等图表
5. **保存配置**: 在"参数编辑器"的"导入/导出"选项卡保存参数

## 技术栈

- **Web框架**: Streamlit 1.28+
- **可视化**: Plotly 5.17+
- **数据处理**: Pandas 2.0+
- **仿真引擎**: MuJoCo (已在 .venv-mujoco 中)

## 常见问题

### Q: 如何保存当前参数？
A: 在"参数编辑器" → "导入/导出"选项卡 → 点击"下载 YAML"

### Q: 仿真运行失败怎么办？
A: 勾选"显示详细日志"查看错误信息，检查参数是否合理
