# IMU传感器选型指南

## 概述

本文档对比脑卒中步态检测系统中可用的6轴IMU传感器（3轴加速度计 + 3轴陀螺仪），提供选型建议。

**应用场景：** 可穿戴步态采集设备，用于采集患者行走数据，对比V01-V24仿真研究得出的健康步态基准。

**不是：** 机器人驱动控制（那是V22硬件样机的任务）

---

## 候选方案对比

### 方案1: MPU6050 ⭐ 推荐入门

**技术参数:**
- **传感器类型**: 6轴 (3轴加速度计 + 3轴陀螺仪)
- **加速度范围**: ±2g / ±4g / ±8g / ±16g (可配置)
- **陀螺仪范围**: ±250°/s / ±500°/s / ±1000°/s / ±2000°/s (可配置)
- **分辨率**: 16位ADC
- **采样率**: 最高1kHz
- **通信接口**: I2C (地址0x68/0x69)
- **工作电压**: 3.3V - 5V
- **工作电流**: 3.9mA (正常模式)
- **封装**: QFN-24 (4×4mm)
- **价格**: ¥8-12/个 (GY-521模块)

**核心特性:**
- 内置DMP (Digital Motion Processor) - 可输出四元数、欧拉角
- 16位温度传感器
- 可编程数字滤波器
- 中断引脚支持
- 多个I2C设备级联（最多8个，需地址选择）

**优点:**
- ✅ 社区资源最丰富（Arduino库、教程、论坛）
- ✅ 价格便宜，适合原型开发
- ✅ DMP功能简化姿态解算
- ✅ 供货稳定，多家厂商生产
- ✅ 调试工具完善

**缺点:**
- ❌ 精度一般（陀螺仪零偏漂移明显）
- ❌ 温度补偿效果有限
- ❌ 功耗较高（对比新一代产品）
- ❌ 噪声水平中等

**适用场景:**
- 原型验证阶段
- 算法开发与测试
- 教学演示
- 成本敏感项目

**典型噪声水平:**
- 加速度噪声密度: 400 μg/√Hz
- 陀螺仪噪声密度: 0.005 °/s/√Hz

### 方案2: BMI160 ⭐⭐ 推荐量产

**技术参数:**
- **传感器类型**: 6轴 (3轴加速度计 + 3轴陀螺仪)
- **加速度范围**: ±2g / ±4g / ±8g / ±16g (可配置)
- **陀螺仪范围**: ±125°/s / ±250°/s / ±500°/s / ±1000°/s / ±2000°/s (可配置)
- **分辨率**: 16位ADC
- **采样率**: 最高1.6kHz
- **通信接口**: I2C / SPI (最高10MHz)
- **工作电压**: 1.71V - 3.6V
- **工作电流**: 950μA (加速度+陀螺仪同时工作)
- **封装**: LGA-14 (2.5×3.0×0.8mm)
- **价格**: ¥15-20/个

**核心特性:**
- **低功耗模式**: 
  - 加速度单独: 180μA
  - 陀螉仪单独: 900μA
  - 休眠模式: <5μA
- 内置FIFO (1024字节)
- 可编程中断引擎（步数检测、跌倒检测）
- 自测功能
- 温度传感器

**优点:**
- ✅ **超低功耗** (是MPU6050的1/4)
- ✅ 精度更高，零偏稳定性好
- ✅ 温度稳定性优秀（±0.02°/s/°C）
- ✅ 体积极小，适合可穿戴
- ✅ Bosch品质保证

**缺点:**
- ❌ Arduino库支持不如MPU6050
- ❌ 价格略高
- ❌ 调试资料相对较少
- ❌ 需要更复杂的初始化配置

**适用场景:**
- 产品化阶段
- 需要长续航（>4小时）
- 可穿戴设备
- 多传感器节点

**典型噪声水平:**
- 加速度噪声密度: 180 μg/√Hz
- 陀螺仪噪声密度: 0.007 °/s/√Hz

## 硬件接口设计

### I2C总线拓扑（推荐）

```
ESP32 (主控)
  │
  ├─ I2C总线 (SDA, SCL)
  │   ├─ MPU6050 #1 (0x68) - 左大腿
  │   ├─ MPU6050 #2 (0x69) - 左小腿  [AD0→VCC]
  │   ├─ MPU6050 #3 (0x68) - 右大腿  [通过TCA9548A复用器]
  │   └─ MPU6050 #4 (0x69) - 右小腿  [通过TCA9548A复用器]
  │
  └─ I2C总线扩展方案:
      - 方案A: 使用TCA9548A (8通道I2C多路复用器)
      - 方案B: 两条独立I2C总线 (ESP32支持)
```

### 地址冲突解决方案

**MPU6050地址选择:**
- AD0引脚 → GND: 地址0x68
- AD0引脚 → VCC: 地址0x69

**4个传感器布局:**
1. 左大腿: 0x68 (AD0→GND)
2. 左小腿: 0x69 (AD0→VCC)
3. 右大腿: 通过TCA9548A通道0
4. 右小腿: 通过TCA9548A通道1

## 传感器标定

### 加速度计标定

**六面静态标定法:**

```python
# 将传感器依次放置在六个面上静止10秒
# 理论值:
# +X朝上: [+1g, 0, 0]
# -X朝上: [-1g, 0, 0]
# +Y朝上: [0, +1g, 0]
# -Y朝上: [0, -1g, 0]
# +Z朝上: [0, 0, +1g]
# -Z朝上: [0, 0, -1g]

import numpy as np

def calibrate_accelerometer(six_face_readings):
    """
    six_face_readings: shape (6, 3)
    返回: offset (3,), scale (3,)
    """
    # 计算零偏
    offset = np.mean([
        (six_face_readings[0] + six_face_readings[1]) / 2,
        (six_face_readings[2] + six_face_readings[3]) / 2,
        (six_face_readings[4] + six_face_readings[5]) / 2
    ], axis=0)
    
    # 计算比例因子
    scale = np.array([
        abs(six_face_readings[0][0] - six_face_readings[1][0]) / 2,
        abs(six_face_readings[2][1] - six_face_readings[3][1]) / 2,
        abs(six_face_readings[4][2] - six_face_readings[5][2]) / 2
    ])
    
    return offset, scale

# 使用标定参数
accel_corrected = (accel_raw - offset) / scale
```

### 陀螺仪标定

**零偏标定:**

```python
def calibrate_gyroscope(static_readings, duration=10.0, fs=100):
    """
    static_readings: shape (n_samples, 3) - 静止状态下采集
    返回: gyro_offset (3,)
    """
    gyro_offset = np.mean(static_readings, axis=0)
    gyro_noise_std = np.std(static_readings, axis=0)
    
    print(f"陀螉仪零偏: {gyro_offset}")
    print(f"噪声标准差: {gyro_noise_std} °/s")
    
    return gyro_offset

# 使用
gyro_corrected = gyro_raw - gyro_offset
```

## 数据采集规范

### 采样率选择

| 应用场景 | 推荐采样率 | 理由 |
|---------|-----------|------|
| 步态周期检测 | 100 Hz | 步频<2Hz，Nyquist定理要求>4Hz |
| 关节角度估计 | 200 Hz | 捕捉快速摆动相 |
| 足底冲击检测 | 500 Hz | 足跟着地冲击持续<50ms |
| 研究级精度 | 1000 Hz | 捕捉所有细节 |

**本项目推荐: 200Hz**（平衡精度与功耗）

## 故障排查

### 常见问题

#### 1. I2C通信失败

**症状:** 
```
ERROR: MPU6050 not found at address 0x68
```

**排查步骤:**
1. 检查接线（SDA/SCL是否接反）
2. 检查上拉电阻（需要4.7kΩ）
3. 运行I2C扫描程序:
```cpp
#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(115200);
  
  for(byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if(Wire.endTransmission() == 0) {
      Serial.printf("Found device at 0x%02X\n", addr);
    }
  }
}
```

#### 2. 数据漂移严重

**症状:** 陀螺仪积分角度在静止时持续增长

**原因:** 零偏未标定

**解决:** 
1. 上电后静止10秒采集零偏
2. 实时减去零偏值
3. 使用互补滤波融合加速度计

#### 3. 多传感器数据不同步

**症状:** 4个IMU读数时间戳相差>10ms

**解决:**
1. 使用硬件中断同步采集
2. 主循环中依次快速读取（<5ms）
3. 使用FIFO缓冲（BMI160/LSM6DS3支持）
