## 1. 概述

V24 的目标是设计 Sim-to-real 迁移策略，使仿真中训练的控制器能够在真实硬件上工作。

## 2. Sim-to-real Gap 分析

### 2.1 已知差异来源

| 差异类型 | 仿真 | 现实 | 影响 |
|---------|------|------|------|
| 接触模型 | MuJoCo 软接触 | 刚性+弹性混合 | 触地冲击 |
| 摩擦力 | 常数 μ=1.35 | 速度相关 | 滑动行为 |
| 电机延迟 | 0 ms | 5-10 ms | 控制带宽 |
| 传感器噪声 | 理想或高斯 | 非高斯+偏差 | 状态估计 |
| 环境扰动 | 无 | 气流、振动 | 鲁棒性 |

### 2.2 V16/V17 已建模部分

- 电机摩擦（V16 + V13.7 补偿）✓
- 传感器量化和延迟（V17）✓
- 转动惯量和粘滞阻尼（V16）✓

## 3. 域随机化策略

### 3.1 随机化参数

在仿真中随机化以下参数：

| 参数 | 名义值 | 随机范围 | 分布 |
|------|--------|----------|------|
| 质量 | 5.3 kg | ±10% | 均匀 |
| 腿长 | 1.02 m | ±5% | 均匀 |
| 摩擦系数 | 1.35 | 1.0-1.6 | 均匀 |
| 弹簧刚度 | 0.8/10.0 | ±20% | 高斯 |
| 电机延迟 | 5 ms | 0-15 ms | 均匀 |
| 地面刚度 | 标准 | 0.5-2.0× | 对数正态 |

### 3.2 训练流程

1. 生成 100 组随机配置
2. 每组运行 V13.7 控制器
3. 记录成功率（目标 >50%）
4. 失败案例分析 → 调整控制器增益

```python
# 根据状态估计不确定性调整增益
if state_uncertainty > threshold:
```

```python

if phase == "stance_late":
    tau_max = 4.0  # 标准

    tau_max = 3.5  # 降低（对不确定性敏感）
```

## 5. 首次上机策略

1. **保守参数**：降低所有增益至 70%
2. **人工辅助**：首次行走人工侧向支撑
3. **渐进式**：从静态 → 单步 → 多步 → 连续行走
4. **安全监控**：IMU 跌倒检测 + 急停
5. **数据记录**：对比仿真预测 vs 实际表现
