# V21 快速探索方案（由 Subagent 设计）

**目标**：量化 V19 最佳配置在 3D 扰动下的侧向不稳定程度

## 实验设计（1-2 天可完成）

### 优先级 1：初始 Roll 扰动（4 小时）
测试 7 个配置：`init_hip_roll_deg` = 0°, ±1°, ±2°, ±3°
- **测量**：alternations vs 初始 roll
- **预期**：衰减曲线，量化"从多大初始倾斜开始不可恢复"

### 优先级 2：侧向脉冲（4 小时）
测试 6 个脉冲强度：Fy = 0, 5, 10, 15, 20, -10 N
- **施力时间**：第 2.0s（约第 4-5 步后）
- **测量**：临界脉冲强度（50% 失败率）

### 优先级 3：随机风（可选，4 小时）
测试 5 个风强度：std = 0, 1, 2, 3, 5 N
- **测量**：wind_std → 平均存活时间

## 预期成果

**定量指标**：
- `init_roll_tolerance_deg`：1.5°（50% 成功率）
- `critical_impulse_N`：12 N（导致立即失败）
- `wind_tolerance_std_N`：2.5 N（平均维持 5 步）

**Verdict**：
```
lateral_instability_quantified
V19 在无扰动下仅 7 alt，任何小扰动（2° roll 或 10N 推力）
都会显著缩短存活时间
```

**学术价值**：
- 量化"侧向稳定裕度"（初始条件容差 <2°）
- 为"放弃 3D 化"决策提供硬数据支持

## 实施路径

1. 复用 V19 代码和模型
2. 集成 `common/disturbance.py`
3. 添加随机风逻辑
4. 运行 18 个核心配置
5. 分析和可视化

**总时间**：核心 8 小时（1 天），含分析 12 小时（1.5 天）
