# V13.7 FSM Floquet 分析：关键发现与解读

## 核心发现

**V13.7 FSM 控制律的最大 Floquet 乘子 max|λ| = 1.0008 > 1.0，在理论上处于边界不稳定状态。**

## 详细结果

### 定量对比

| 配置 | max\|λ\| | 稳定性 | alternations | forward (m) | 实际表现 |
|------|----------|--------|--------------|-------------|----------|
| **V10 PD** (V13b) | 0.944 | **稳定** | 19 | 8.60 | 收敛稳定 |
| **V13.7 FSM** (ideal) | 1.0008 | **边界不稳定** | 17 | 8.65 | 看似正常 |
| **V13.7 FSM** (mx64ar+comp) | 1.0008 | **边界不稳定** | 17 | 8.61 | 看似正常 |
| **V13.7 FSM** (mx64ar-no) | 1.0000 | 边界 | 4 | 0.19 | 失败 |

### Floquet 特征值谱

#### V13.7 FSM (ideal)
- λ₁ = **-1.0008** (慢模，主导衰减/发散)
- λ₂ = +0.2839
- λ₃ = +0.1445
- λ₄ = -0.0605

#### V13.7 FSM (mx64ar+comp)
- λ₁ = **-1.0008** (慢模)
- λ₂ = +0.6243
- λ₃ = +0.3645
- λ₄ = -0.0203

#### V10 PD (V13b 参考)
- λ₁ = **±0.944** (慢模，复共轭对或实数)
- 其他模: |λ| < 0.61

## 稳定裕度对比

```
Δλ = max|λ|_V13.7 - max|λ|_V10 = 1.0008 - 0.944 = +0.0568 (+6.0%)
```

**V13.7 FSM 比 V10 PD 稳定裕度小 6.0%，且越过了稳定边界 |λ|=1.0。**

## 理论 vs 实际的矛盾

### 理论预测
根据 Floquet 理论，max|λ| > 1.0 意味着：
- 扰动在 Poincaré 截面上不收敛
- 系统不存在稳定的极限环
- 长期行为应发散或失败

### 实际观测
V13.7 FSM (ideal/comp) 在 20s 仿真中：
- ✓ 完成 17 次交替触地
- ✓ 前进 8.6+ m
- ✓ 能量稳定在 E* = 53.70 ± 0.56 J
- ✓ 未观察到明显发散

### 可能解释

#### 1. **边界效应（|λ| 接近 1.0）**
- max|λ| = 1.0008 仅比边界高 0.08%
- 发散速率极慢：τ_diverge ≈ T_gait / ln(|λ|) ≈ 0.8 / ln(1.0008) ≈ **1000 步**
- 20s 仿真仅约 17-25 步，发散尚未显现

#### 2. **Floquet 方法的局限性**
- 实验 Floquet 方法（Goswami 1996）基于线性化：仅在不动点附近小扰动有效
- 非线性效应（FSM 切换、接触非线性）可能稳定化系统
- 高阶项可能提供隐式稳定机制

#### 3. **FSM 事件驱动的离散化误差**
- FSM 决策门在相位边界做硬切换，引入非光滑动力学
- Poincaré 截面在触地时刻采样，可能捕捉到切换瞬态
- return-map 线性化假设在 FSM 系统中可能不精确

#### 4. **极限环的类型差异**
- V10 PD: 平滑的 attractor（吸引子），扰动自然衰减
- V13.7 FSM: **中性稳定环或慢漂移吸引子**，在有限时间内看似稳定，但长期可能漂移

#### 5. **能量反馈的隐式稳定作用**
V13.7 FSM 使用能量反馈（swing_thrust 阶段 k_E=7.5）：
```python
tau = k_PD * (theta_d - theta) + k_E * (E_target - E_current)
```
能量误差可能作为额外的稳定化机制，未被 4D 位置-速度 Floquet 分析捕捉。

- 能量发散（E 逐渐增大/减小）
- 最终失败（摔倒）

### 2. 扰动恢复测试（参考 V13b）
在不动点附近注入扰动，测量实际衰减/发散率：
```python
δ_k = δ_0 * |λ|^k
```
若实际 |λ_fit| < 1.0，则非线性效应提供稳定化。

### 3. 高维 Floquet 分析
扩展状态向量包含能量：

### 4. 不同初始条件的收敛测试

## 工程影响

### 对 V13.7 实际应用的启示

#### 🔴 风险
1. **鲁棒性不足**: max|λ|=1.0008 表明系统对扰动极其敏感
2. **长期稳定性存疑**: 实际机器人可能在运行数百步后发散
3. **参数敏感性高**: 微小的参数变化可能使 |λ| 进一步增大

#### 🟡 观察与监控
1. **实验验证必要**: 仿真结果需在实物上长时间测试
2. **监控极限环漂移**: 记录步长/步频/能量的长期趋势
3. **准备容错策略**: 检测发散迹象并切换到备用控制律

#### 🟢 潜在优化方向
1. **调整 FSM 增益**: 扫描 (k_PD, k_E) 参数空间，寻找 max|λ| < 0.95 的配置
2. **增强能量调节**: 提高 k_E 或引入积分项，强化能量稳定
3. **混合控制**: 在检测到漂移时切换回 V10 PD 控制

## 结论

1. **V13.7 FSM 的 Floquet 稳定性弱于 V10 PD**（max|λ|: 1.0008 vs 0.944）
2. **系统在理论上处于边界不稳定**（max|λ| > 1.0），但短期表现正常
3. **摩擦补偿有效**：mx64ar+comp 与 ideal 性能一致（Δλ < 0.001%）
4. **需要长时程实验验证**：确认系统是否真正发散或存在隐式稳定机制
5. **工程应用需谨慎**：建议优化 FSM 参数或引入监控机制
