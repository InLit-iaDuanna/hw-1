# hw-1 版本依赖关系可视化系统

展示 V01-V24 的技术演化路线、版本依赖、决策分支。

## 文件说明

- **extract_dependencies.py** - 从文档提取依赖关系，生成图数据
- **graph_data.json** - 节点和边的完整数据（35 个版本，40 条依赖关系）
- **visualize_graph.py** - 使用 Graphviz 生成静态图（需安装 Graphviz）
- **interactive_graph.html** - 交互式可视化（使用 vis.js，可直接在浏览器打开）

## 快速开始

### 查看交互式图形

直接在浏览器中打开 `interactive_graph.html` 即可查看交互式版本依赖图。

**功能特性：**
- 🎯 高亮主线路径（V05→V06→V10→...→V22→V25）
- 🚪 标注决策门（V13, V14, V14c, V16, V18, V20）
- 🔍 阶段筛选（阶段1-4）
- 📦 类型筛选（理论证明/机械转译/真实接触/硬件等）
- 💡 鼠标悬停显示详情
- 🔗 点击节点查看完整信息

### 生成静态图形

如果需要生成 PNG 格式的静态图：

```powershell
# 1. 安装 Graphviz 系统工具（需要安装系统级 Graphviz）
# 下载地址: https://graphviz.org/download/

# 2. 添加 Graphviz 到系统 PATH

# 3. 运行生成脚本
.venv-mujoco\Scripts\python.exe version_graph\visualize_graph.py
```

生成的图形：
- `full_graph.png` - 完整依赖图（所有版本和边）
- `main_line_graph.png` - 主线简化图（仅主线版本）

### 更新图数据

如果文档有更新，重新提取依赖关系：

```powershell
.venv-mujoco\Scripts\python.exe version_graph\extract_dependencies.py
```

## 技术细节

### 节点属性

每个版本节点包含：
- **id**: 版本号（如 V13.7）
- **name**: 版本名称
- **stage**: 阶段（1-4）
- **type**: 类型（理论证明/机械转译/真实接触/分析层/硬件/探索层）
- **status**: 状态（已完成/纯被动/准被动/失败/设计文档/否定结果）
- **description**: 描述
- **key_metrics**: 关键指标（成功率/CoT/forward 等）
- **is_main_line**: 是否主线版本

### 边属性

每条依赖边包含：
- **source**: 源版本
- **target**: 目标版本
- **type**: 依赖类型（直接继承/参考对照/分支探索/并行分支）
- **description**: 关系描述

## 使用场景

1. **论文撰写** - 展示技术演化路径，说明方法论迭代
2. **答辩准备** - 可视化主线路径，突出关键决策点
3. **项目复盘** - 分析否定结果的价值，识别分支决策依据
4. **新成员入职** - 快速理解项目历史和技术脉络
5. **未来规划** - 基于现有路径规划 V26+ 的方向

## 维护说明

当新增版本时，需要：

1. 编辑 `extract_dependencies.py`
2. 在 `nodes` 列表中添加新版本节点
3. 在 `edges` 列表中添加依赖关系
4. 运行 `extract_dependencies.py` 重新生成 `graph_data.json`
5. 刷新 `interactive_graph.html` 查看更新

## 已知问题

- **Graphviz 静态图生成**需要系统安装 Graphviz 工具，中文标签可能需要字体配置
- **交互式图形**在节点过多时（>50）布局可能较慢，可考虑分阶段展示
- **边的交叉**在复杂依赖关系中难以完全避免，建议使用筛选功能聚焦特定路径
