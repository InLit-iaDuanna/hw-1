## 2. 关键部件设计

### 2.1 髋部质量块（Hip_Mass_Block）

**功能**: 
- 集中质量（>90% 总质量）
- 安装左右髋电机
- 连接导轨滑块
- 固定躯干和电子设备

**设计要点**:
```
材料: 6061 铝合金基座 + 铅块配重

尺寸:
- 长×宽×高: 150mm × 100mm × 80mm
- 质量: 5.0 kg（铝 1.5 kg + 铅 3.5 kg）

特征:
1. 顶部平面: 安装躯干管（Φ30mm 孔，深 20mm）
2. 两侧面: 安装 Dynamixel 电机
   - 孔距: 按 MX-64AR 安装孔（32mm × 50mm）
   - 沉孔: M3 螺丝头
3. 前后侧面: 安装导轨滑块（4×M5 螺纹孔）
4. 内部空腔: 嵌入铅块配重
5. 底部: 预留安全绳索安装点
```

**CAD 建模步骤**:
1. 拉伸 150×100×80mm 长方体
2. 顶部打 Φ30mm 孔（深 20mm）
3. 两侧面添加 MX-64AR 安装孔阵列
4. 前后面添加 M5 螺纹孔（导轨滑块）
5. 内部挖空 60×60×50mm 配重腔
6. 倒角 3mm（所有外边缘）

**工程图标注**:
- 关键尺寸公差: ±0.1mm（安装孔）
- 表面粗糙度: Ra 3.2（安装面）
- 材料标注: 6061-T6 铝合金

### 2.2 大腿杆（Thigh）

**功能**:
- 连接髋关节和膝关节
- 承受弯曲和扭转载荷

**设计要点**:
```
材料: 铝合金空心管 Φ20×1.5mm

尺寸:
- 长度: 490mm（实际切割 495mm，两端各留 2.5mm 余量）
- 质量: 约 0.18 kg

连接方式:
- 上端: 通过 L 型支架连接电机 horn
- 下端: 通过关节轴连接膝关节
```

**端部处理**:
```
上端（髋侧）:
- 打 2×Φ4mm 孔（间距 25mm）
- 与 L 型支架螺栓连接

下端（膝侧）:
- 打 1×Φ8mm 孔（穿关节轴）
- 两侧加固板（防止管壁变形）
```

**CAD 建模**:
1. 画 Φ20mm 圆（壁厚 1.5mm）
2. 拉伸 490mm
3. 上端打 2×Φ4mm 孔（间距 25mm，距端面 15mm）
4. 下端打 1×Φ8mm 孔（距端面 20mm）
5. 添加加固板（2mm 厚铝片，焊接或铆接）

### 2.3 膝关节（Knee_Joint）

**功能**:
- 连接大腿和小腿
- 安装 Dynamixel 电机
- 集成被动扭簧（0.8 N·m/rad）

**设计要点**:
```
组成:
1. 电机本体（MX-64AR）
2. 电机 horn（连接大腿）
3. 输出轴（连接小腿）
4. 扭簧安装座
5. 限位挡块（0° ~ 70°）

扭簧集成方式:
- 扭簧一端固定在电机外壳
- 另一端固定在输出轴（小腿侧）
- 零位：膝关节伸直（0°）
```

**CAD 建模**:
1. 导入 MX-64AR 3D 模型（从 Robotis 官网下载）
2. 设计扭簧安装座（C 型卡箍，夹在电机外壳）
3. 设计输出轴连接件（连接小腿管）
4. 添加限位挡块（防止膝盖反向弯曲）

### 2.4 脚底（Foot）

**功能**:
- 滚动接触地面
- 分散触地冲击
- 提供摩擦力

**设计要点**:
```
形状: 弧形（半径 40mm）

分段设计:
- 脚跟: 半径 40mm 圆弧，长 30mm
- 足底: 半径 40mm 圆弧，长 60mm
- 脚趾: 半径 28mm 圆弧，长 30mm

材料:
- 主体: PLA 3D 打印（填充率 30%）
- 外层: 5mm 橡胶垫（粘贴）

接触传感器安装:
- 足底中部预留微动开关安装槽
- 走线孔通向小腿管内部
```

**3D 打印设置**:
```
切片参数:
- 层高: 0.2mm
- 填充: 30%（网格）
- 壁厚: 2mm（4 层）
- 支撑: 需要（脚趾悬空部分）
- 打印方向: 脚底朝下（减少支撑）
```

**STL 文件导出**:
- 文件名: `Foot_Left.stl`, `Foot_Right.stl`
- 单位: mm
- 检查: 无漏洞、无翻转法向量

### 2.5 踝关节（Ankle_Joint）

**功能**:
- 被动旋转（-25° ~ +25°）
- 提供弹性复位（10 N·m/rad）
- 吸收冲击

**设计要点**:
```
结构:
- 轴: Φ8mm 不锈钢轴，长 60mm
- 轴承: 608ZZ × 2（小腿侧）
- 扭簧: 刚度 10 N·m/rad
- 限位: 挡块限制 ±25°

装配:
1. 小腿管下端打 Φ8mm 横孔
2. 轴承压入小腿管两侧
3. 关节轴穿过轴承
4. 脚底通过 L 型支架固定在轴上
5. 扭簧一端固定在小腿，另一端固定在脚底
```

**扭簧选型**:
- 内径: Φ10mm（套在关节轴上）
- 圈数: 根据刚度定制（约 8-10 圈）
- 线径: 2mm 钢丝

### 2.6 躯干（Torso）

**功能**:
- 安装电子设备（树莓派、电池）
- 提供侧向约束连接点（如悬吊）

**设计要点**:
```
材料: 碳纤维管 Φ30mm, 壁厚 2mm, 长 300mm

安装:
- 下端: 插入髋部质量块顶部孔（Φ30mm）
- 上端: 安装平台（固定树莓派和电池）

载荷:
- 树莓派 + 外壳: 100g
- 电池: 200g
- 线缆和固定件: 50g
- 总计: 350g

固定方式:
- 管内插入铝棒（Φ28mm, 长 50mm）
- 穿销钉（Φ4mm）防旋转
```

**顶部平台设计**:
```
尺寸: 150mm × 100mm × 3mm
材料: 碳纤维板或铝板
安装孔:
- 树莓派: 4×M2.5（58mm × 49mm 孔距）
- 电池: 魔术贴固定
- 线缆扎带槽
```

## 3. 装配关系

### 3.1 关节自由度

| 关节 | 类型 | 轴向 | 范围 |
|------|------|------|------|
| 左髋 | 旋转 | Y 轴 | -95° ~ +95° |
| 右髋 | 旋转 | Y 轴 | -95° ~ +95° |
| 左膝 | 旋转 | Y 轴 | 0° ~ 70° |
| 右膝 | 旋转 | Y 轴 | 0° ~ 70° |
| 左踝 | 旋转（被动）| Y 轴 | -25° ~ +25° |
| 右踝 | 旋转（被动）| Y 轴 | -25° ~ +25° |

### 3.2 配合关系

```
配合类型:
1. 间隙配合: 轴承-轴（H7/f6）
2. 过盈配合: 轴承-轴承座（H7/p6）
3. 螺纹连接: M3/M4/M5 螺栓
4. 销钉固定: Φ4mm 弹簧销
5. 粘接: 橡胶-脚底（502 胶）
```

### 3.3 质心计算

使用 CAD 软件的"质量属性"功能验证：
- 总质心高度 ≈ 0.85 m（站立姿态）
- 总质量 ≈ 5.5 kg
- 转动惯量（绕髋部 Y 轴）≈ 1.2 kg·m²

目标: 与仿真参数偏差 <5%

## 4. 材料和加工

### 4.1 材料清单

| 部件 | 材料 | 热处理 | 表面处理 |
|------|------|--------|----------|
| 髋部质量块 | 6061-T6 | 已时效 | 阳极氧化 |
| 大腿/小腿管 | 6063-T5 | 已时效 | 无 |
| 躯干管 | 碳纤维 | - | 无 |
| 关节轴 | 304 不锈钢 | - | 抛光 |
| 连接件 | 6061 / ABS | - | 无 |
| 脚底 | PLA | - | 无 |

### 4.2 加工工艺

**髋部质量块**:
```
工艺:
1. 铣床加工外形（150×100×80mm）
2. 数控钻孔（安装孔阵列）
3. 攻丝 M3/M5
4. 内部铣空配重腔
5. 倒角去毛刺
6. 阳极氧化（可选）

公差:
- 外形尺寸: ±0.2mm
- 安装孔位置: ±0.1mm
- 螺纹: 6H
```

**管材加工**:
```
工艺:
1. 切割（锯床或管材切割机）
2. 端面铣平
3. 钻孔（台钻或数控）
4. 去毛刺

注意:
- 夹持时避免压扁管壁
- 钻孔前用样冲定位
```

### 4.3 外协加工建议

如自行加工困难，可外协：
- **髋部质量块**: 机加工店（提供 2D 工程图）
- **管材**: 五金店切割 + 自行钻孔
- **脚底**: 3D 打印服务（上传 STL）
- **连接件**: 激光切割（2D 钢板/铝板）

## 6. 仿真验证

### 6.1 质量属性对照

从 CAD 导出的质量属性应与仿真参数一致：

| 参数 | 仿真值 | CAD 值 | 允许偏差 |
|------|--------|--------|----------|
| 总质量 | 5.3 kg | ≈5.5 kg | ±5% |
| 腿长 | 1.02 m | ≈1.00 m | ±2% |
| 髋部质量占比 | >90% | >90% | - |

### 6.2 运动学仿真

在 CAD 中添加运动副，模拟行走姿态：
1. 左腿支撑，右腿摆动
2. 髋关节角度: -14° ~ +22°
3. 膝关节角度: 0° ~ 28°
4. 检查无干涉

### 6.3 有限元分析（可选）

对高应力部件进行 FEA：
- 髋部质量块（着陆冲击载荷）
- 大腿管（弯曲应力）
- 关节连接处（剪切应力）

目标: 安全系数 >2.0

## 7. 文件管理

### 7.1 目录结构

```
v22_hardware_design/CAD/
├─ Main_Assembly.sldasm (总装配)
├─ Hip_Assembly.sldasm (髋部子装配)
├─ Left_Leg_Assembly.sldasm (左腿子装配)
├─ Right_Leg_Assembly.sldasm (右腿子装配)
├─ Parts/
│   ├─ Hip_Mass_Block.sldprt
│   ├─ Thigh.sldprt
│   ├─ Shank.sldprt
│   ├─ Foot_Left.sldprt
│   ├─ Foot_Right.sldprt
│   └─ ...
├─ Drawings/
│   ├─ A01_Assembly.pdf
│   ├─ P01_Hip_Mass_Block.pdf
│   └─ ...
└─ Export/
    ├─ Foot_Left.stl (3D 打印)
    ├─ Foot_Right.stl
    └─ Assembly_STEP.stp (通用格式)
```

### 7.2 版本控制

- 文件命名: `PartName_v1.0.sldprt`
- 重大修改递增主版本号: v2.0
- 小修改递增次版本号: v1.1
- 保留历史版本（重命名为 `_archive`）

### 7.3 协作共享

- 输出格式: STEP (.stp) 或 IGES (.igs)
- 3D 打印: STL 格式
- 渲染展示: OBJ 或 FBX 格式
