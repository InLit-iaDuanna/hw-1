# V22 硬件设计规格书

**版本**: v1.0  
**日期**: 2026-06-04  
**基于仿真**: V13.7 (摩擦补偿 FSM) + V17 (状态估计)  
**设计类型**: 2D 矢状面准被动行走机器人

## 1. 设计概述

### 1.1 设计目标

构建一个 2D 约束下的准被动行走机器人，验证 V13.7 FSM 控制律和 V17 状态估计算法在真实硬件上的可行性。

### 1.2 设计原则

1. **仿真一致性优先**: 硬件参数尽可能接近 V13.7/V17 仿真参数
2. **可制造性**: 使用标准件和常见加工工艺
3. **可调试性**: 关键参数可调节（弹簧刚度、质量分布）
4. **安全性**: 低速行走（<0.5 m/s），软着陆机制

### 1.3 约束条件

- **2D 约束**: 使用侧向导轨或悬吊系统限制侧向运动
- **坡度**: 0° 平地（初期），后续可调至 0-3°
- **行走距离**: ≥5 m 连续行走

### 2.3 关节配置

#### 髋关节 (Hip)
- **类型**: 主动旋转关节，双侧独立驱动
- **运动范围**: -95° ~ +95°（仿真限制）
- **阻尼**: 0.02 N·m·s/rad（仿真值）
- **硬件实现**: Dynamixel MX-64AR × 2

#### 膝关节 (Knee)
- **类型**: 主动 + 被动弹簧旋转关节
- **运动范围**: 0° ~ 70°（单向，防止反向弯曲）
- **弹簧刚度**: 0.8 N·m/rad（仿真值）
- **阻尼**: 0.08 N·m·s/rad
- **硬件实现**: Dynamixel MX-64AR × 2 + 扭簧

#### 踝关节 (Ankle)
- **类型**: 被动弹簧旋转关节
- **运动范围**: -25° ~ +25°
- **弹簧刚度**: 10.0 N·m/rad（仿真值）
- **阻尼**: 0.08 N·m·s/rad
- **硬件实现**: 轴承 + 可调扭簧 + 阻尼片

### 2.4 足底设计

- **形状**: 弧形滚动足（半径 40 mm）
- **材料**: PLA 3D 打印 + 橡胶防滑垫
- **接触点**: 脚跟、足底中部、脚趾（三点接触）
- **摩擦系数**: μ ≥ 1.2（橡胶-木地板）

## 3. 电机选型

### 3.1 主驱动电机

**型号**: Dynamixel MX-64AR  
**数量**: 4 个（左右髋关节 × 2，左右膝关节 × 2）

| 参数 | 规格 | 仿真对应值 |
|------|------|-----------|
| 额定扭矩 | 6.0 N·m | τ_limit = 4.0 N·m（软件限制）|
| 堵转扭矩 | 7.3 N·m | τ_sat_peak = 6.0 N·m |
| 无负载转速 | 63 RPM | - |
| 转子惯量 | 2.8×10⁻³ kg·m² | J_eff = 2.8e-3 |
| 库仑摩擦 | τ_C ≈ 0.20 N·m | 已在 V13.7 补偿 |
| 粘滞阻尼 | b ≈ 0.05 N·m·s/rad | joint_damping 折算 |
| 编码器分辨率 | 4096 CPR | V17 传感器模型验证 |
| 通信接口 | TTL / RS485 | 菊花链连接 |
| 工作电压 | 11.1-14.8 V | 3S LiPo (11.1V 标称)|
| 峰值电流 | 4.1 A | I_max = 4.5 A (仿真)|

**选型理由**:
1. V16/V17 仿真中已验证 MX-64AR 参数
2. V13.7 摩擦补偿算法针对此电机设计
3. 高精度编码器满足 V17 状态估计要求（<15 ms 延迟）

### 3.2 电源系统

- **电池**: 3S LiPo 11.1V 2200mAh
- **放电能力**: 25C（55A 连续）
- **估算续航**: 
  - 单电机平均功率 ≈ 4 N·m × 1 rad/s = 4 W
  - 4 电机 + 控制板 ≈ 20 W
  - 续航时间 ≈ 11.1V × 2.2Ah / 20W ≈ 1.2 小时

## 4. 传感器配置

### 4.1 关节位置/速度传感器

**来源**: Dynamixel MX-64AR 内置编码器

| 参数 | 规格 | V17 验证结果 |
|------|------|-------------|
| 分辨率 | 4096 CPR | 满足要求（≥1024） |
| 角度精度 | 0.088° | - |
| 速度估计 | 片上计算 | Kalman 滤波后 RMSE <0.08 m/s |
| 更新频率 | 1 kHz | - |

### 4.2 接触传感器

**类型**: 微动开关或薄膜压力传感器  
**位置**: 每只脚底 1 个（脚跟或足底中部）  
**响应时间**: <10 ms（V17 要求 <15 ms）  
**触发阈值**: ≥5 N（确保稳定接触检测）

**布线**: 通过腿部内部走线至主控板

### 4.3 IMU（可选）

**型号**: MPU6050 或 BNO055  
**用途**: 
- 躯干姿态监测（roll/pitch 角度）
- 跌倒检测（>45° 触发急停）
- 后期数据分析

**安装位置**: 髋部质量块中心

### 4.4 电流/电压传感器

**用途**: 
- 电池电压监测（低电量报警）
- 电机电流监测（过载保护）
- 能耗测量（CoT 实测）

## 5. 控制系统

### 5.1 主控单元

**推荐方案 A**: Raspberry Pi 4B  
- CPU: ARM Cortex-A72 1.5GHz × 4
- RAM: 4 GB
- 操作系统: Ubuntu 20.04 + ROS Noetic
- 控制频率: 1 kHz（实时内核补丁）

**推荐方案 B**: STM32F4 系列  
- 更低延迟（裸机或 RTOS）
- 需要自行实现 FSM 和状态估计

**选型建议**: 初期使用 Raspberry Pi（快速原型），后期优化可移植到 STM32

### 5.2 软件架构

```
硬件层:
  - Dynamixel SDK (电机通信)
  - GPIO (接触传感器)
  - I2C (IMU)

驱动层:
  - 电机命令封装
  - 传感器数据采集
  - 安全监控（紧急停止）

控制层:
  - V13.7 FSM 控制器（从 Python 移植）
  - 摩擦补偿算法
  - V17 状态估计器（Kalman 滤波）

应用层:
  - 数据记录
  - 参数调整接口
  - 远程监控（WiFi）
```

## 6. 2D 约束机构

### 6.1 侧向导轨方案（推荐）

**结构**:
- 铝型材导轨 40×40 mm，长度 6 m
- 直线轴承滑块安装在髋部两侧
- 允许前后移动和绕导轨旋转（roll 自由度保留）

**优点**:
- 侧向约束刚性强
- 可在导轨上安装安全绳索
- 便于调整坡度（倾斜导轨）

**缺点**:
- 滑块摩擦力引入额外阻力（需在仿真中补偿）
- 导轨长度限制行走距离

### 6.2 悬吊方案（备选）

**结构**:
- 顶部龙门架 + 柔性吊绳
- 吊绳通过万向节连接髋部
- 吊绳长度调节控制髋部高度

**优点**:
- 无滑动摩擦
- 行走距离不受限（可沿龙门架移动）

**缺点**:
- 侧向约束较弱（需要吊绳张力控制）
- 摆动惯性影响步态

**推荐**: 初期使用侧向导轨，成熟后尝试悬吊方案

## 7. 安全设计

### 7.1 机械安全

- **限位开关**: 关节极限位置安装微动开关
- **软着陆垫**: 髋部下方安装泡沫垫（防跌倒损坏）
- **急停按钮**: 有线和无线急停（WiFi 或蓝牙）

### 7.2 电气安全

- **过流保护**: 每个电机独立熔断器
- **欠压保护**: 电池电压 <9.5V 自动断电
- **过温保护**: 电机温度 >80°C 降低扭矩限制

### 7.3 软件安全

- **看门狗定时器**: 主循环超时自动复位
- **跌倒检测**: IMU 角度 >45° 触发急停
- **失控检测**: 连续 5 步未检测到交替触地，触发急停

## 11. 后续优化方向

1. **轻量化**: 使用碳纤维杆减重
2. **高性能电机**: 升级到 MX-106 或无刷电机
3. **无线化**: 电池和控制器板载，去除拖线
4. **3D 化**: 增加髋外展关节（基于 V20 步宽控制）
5. **地形适应**: 可调坡度平台，崎岖地形测试
