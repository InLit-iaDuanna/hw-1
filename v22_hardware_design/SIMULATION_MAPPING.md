## 4. 电机参数

### 4.1 Dynamixel MX-64AR

| 参数名 | 仿真变量（V16/V17）| 仿真值 | 硬件规格 | 来源 |
|--------|-------------------|--------|----------|------|
| 转子惯量 | `J_rotor` | 2.8×10⁻³ kg·m² | 2.8×10⁻³ | Datasheet |
| 减速比 | `N` | 200 | 200 | Datasheet |
| 传动效率 | `eta` | 0.70 | 0.70 | 实测估计 |
| 库仑摩擦 | `tau_C_motor` | 1.0×10⁻³ N·m | - | V16 辨识 |
| 粘滞阻尼 | `b_visc_motor` | 1.25×10⁻⁴ N·m·s/rad | - | V16 辨识 |
| 电枢电阻 | `R_arm` | 2.3 Ω | 2.3 Ω | Datasheet |
| 扭矩常数 | `Kt` | 0.058 N·m/A | 0.058 | Datasheet |
| 峰值电流 | `I_max` | 4.5 A | 4.1 A | Datasheet（实际）|
| 连续电流 | `I_cont` | 2.5 A | 2.3 A | Datasheet（实际）|

**关节侧等效参数**（经过减速比折算）:
- `joint_J_eff` = J_rotor × N² / eta = 2.8e-3 × 200² / 0.7 ≈ 1.6 kg·m²（过大，实际取 armature 默认值）
- `joint_b_eff` = b_visc_motor × N² / eta ≈ 0.05 N·m·s/rad
- `joint_tau_C_eff` = tau_C_motor × N = 0.20 N·m（V16 失败带，V13.7 已补偿）
- `joint_tau_sat_peak` = Kt × I_max × N × eta ≈ 6.0 N·m

### 4.2 电机补偿（V13.7）

仿真中的摩擦补偿算法:
```python
tau_comp = tau_C_eff * sign_smooth(omega_joint, eps=0.01)
tau_command = tau_fsm + tau_comp
```

硬件实现:
```cpp
// 在 FSM 输出力矩后添加补偿项
float omega_joint = joint.getPresentVelocity(); // rad/s
float tau_C_eff = 0.20; // N·m（MX-64AR 实测值）
float eps = 0.01; // 平滑参数
float sign_smooth_val = tanh(omega_joint / eps);
float tau_comp = tau_C_eff * sign_smooth_val;
float tau_command = tau_fsm + tau_comp;
joint.setGoalTorque(tau_command); // 发送给电机
```

## 9. 参数校准流程

### 9.1 几何参数校准

1. 使用卡尺测量腿长（精度 0.1 mm）
2. 使用电子秤称量各部件质量（精度 1 g）
3. 在 CAD 中验证质心位置
4. 与仿真参数对比，记录偏差

### 9.2 电机参数校准

1. 使用 Dynamixel Wizard 读取电机参数
2. 验证编码器零位（关节伸直时读数）
3. 测试扭矩限制（逐步增加负载）
4. 记录电流-扭矩曲线（验证 Kt）

### 9.3 传感器校准

1. **接触传感器**:
   - 测量触发力（用弹簧秤）
   - 测量响应时间（示波器）
   - 调整去抖延迟

2. **编码器**:
   - 零位标定（使用水平仪）
   - 精度测试（与外部量角器对比）

3. **IMU**:
   - 加速度计零偏标定
   - 陀螺仪零偏标定
   - 磁力计校准（8 字形摇摆）

### 9.4 控制参数调优

1. 从 V13.7 参数开始
2. 逐步降低增益直至稳定（保守策略）
3. 记录每次调整和结果
4. 最终参数写入配置文件

**偏差处理原则**:
- <5%: 可接受，记录即可
- 5-10%: 需评估影响，可能需调整控制参数
- >10%: 必须修正或重新设计

## 11. 参数调整建议

如实测参数与仿真偏差较大，优先级：

1. **质量分布**（最重要）:
   - 增减配重块调整总质量
   - 确保 >90% 质量在髋部

2. **弹簧刚度**:
   - 更换扭簧（定制不同圈数）
   - 使用可调弹簧座

3. **摩擦系数**:
   - 更换脚底橡胶材料
   - 更换行走地面

4. **电机参数**:
   - 软件调整扭矩限制
   - V13.7 补偿算法中调整 tau_C_eff
