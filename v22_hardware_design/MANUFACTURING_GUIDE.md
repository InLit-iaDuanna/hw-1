```

## 1. 加工工艺详细说明

### 1.1 髋部质量块（最关键件，建议外协机加工）

**材料**: 6061-T6 铝合金块 + 4 块铅块配重
**毛坯尺寸**: 150 × 100 × 80 mm
**目标质量**: 5.0 kg（铝结构 1.5 kg + 铅块配重 3.5 kg）

**加工工序**:

```
工序 01  下料                   规格 155×105×85（含余量 5mm）
工序 02  铣六面               保证垂直度 0.05/100，平面度 0.03
工序 03  铣外形至 150×100×80   表面粗糙度 Ra 3.2
工序 04  铣配重腔（内部）        60×60×50 mm，腔底厚度 ≥10 mm
工序 05  数控钻孔（电机安装侧）   2 组 MX-64AR 安装孔阵列
                              孔位公差 ±0.10 mm
工序 06  数控钻孔（导轨连接侧）   4×M5 螺纹孔，间距 50×50 mm
工序 07  钻顶部躯干孔           Φ30 H8，深 20 mm
工序 08  攻丝                  M3-6H, M4-6H, M5-6H
工序 09  倒角去毛刺             所有外边缘 R3 倒角
工序 10  阳极氧化（可选）        硬质氧化 30 μm，颜色不限
```

**外协报价参考**: 350-500 元（含图纸沟通，3-5 工作日）

**收货验收清单**:

- [ ] 外形尺寸 150×100×80 mm 偏差 ±0.2 mm
- [ ] 电机安装孔间距 32×50 mm 偏差 ±0.1 mm
- [ ] M5 螺纹孔 6H 配合（用螺栓试拧）
- [ ] 配重腔内壁无明显切削痕
- [ ] 重量 1.4-1.6 kg（电子秤测量，未装铅块）

### 1.2 铝管切割（大腿/小腿/躯干）

**所需切割**:

| 部件 | 规格 | 切割长度 | 数量 | 公差 |
|------|------|----------|------|------|
| 大腿 | Φ20×1.5 mm 6063-T5 | 490 mm | 2 | ±0.5 mm |
| 小腿 | Φ18×1.5 mm 6063-T5 | 510 mm | 2 | ±0.5 mm |
| 躯干 | 碳纤维 Φ30×2 mm | 300 mm | 1 | ±1.0 mm |

**自加工流程（推荐）**:

```
1. 用 90° 角尺画切割线（圆周一周）
2. 角磨机 + 1mm 切割片缓慢进刀
   或 手锯（铝管软，10 分钟一根）
3. 锉刀去毛刺（内外两面）
4. 端面铣平（可台钻配端面铣刀）
5. 用游标卡尺确认长度，偏差 >1 mm 重做
```

**钻孔工艺**（每根管子 4 个孔）:

```
位置标记:
  距上端面 15 mm: 钻 Φ4.2 mm 孔（穿 M4 螺栓，与电机 horn 连接）
  距下端面 20 mm: 钻 Φ8.1 mm 孔（穿关节轴）

夹持方法（防压扁）:
  方法 A: V 形铁 + 木块衬垫
  方法 B: 在管内塞入 Φ16 mm 木棒支撑

钻孔顺序:
  1. 用样冲打点（防滑钻头）
  2. Φ3 中心钻定位
  3. Φ4.2 钻头钻通（铝管两侧同时贯通）
  4. 翻面 180° 检查孔同心度（偏差 <0.3 mm）
  5. 倒角 0.5×45°
```

**易错点**:

- 切割面不垂直 → 装配后腿轴歪斜，膝弯曲方向错误
- 钻孔偏心 → 关节轴卡滞，摩擦力增大
- 管壁压扁 → 强度下降，连接松动

### 1.3 3D 打印（脚底）

**打印件清单**:

| 文件 | 尺寸 | 重量 | 材料 |
|------|------|------|------|
| Foot_Left.stl | 约 150×60×80 mm | 110 g | PLA |
| Foot_Right.stl | 约 150×60×80 mm | 110 g | PLA（镜像） |
| 接触开关支架 (×2) | 30×20×10 mm | 5 g | PLA |
| 扭簧固定座 (×4) | 25×25×15 mm | 8 g | PLA |

**切片参数（推荐 Cura/PrusaSlicer）**:

```
喷嘴温度    210 ℃（PLA）
热床温度    60 ℃
层高        0.2 mm
壁数        4 层（壁厚 1.6 mm）
顶/底层数   5 层
填充率      30%（gyroid 蜂窝纹）
打印速度    50 mm/s
支撑        Yes（脚趾悬空部分，自动生成）
打印方向    脚底朝下，弧面朝上
冷却        100% 风扇（除第一层）
```

**质量检验**:

- [ ] 弧面光滑，无明显层纹（不平整 <0.3 mm）
- [ ] 脚底接触面贴合平面，间隙 <1 mm
- [ ] 微动开关安装槽尺寸 19.8×6.4 mm（卡扣紧密）
- [ ] 走线孔 Φ6 mm 通畅
- [ ] 打印件总重量 105-115 g（多则填充率过高）

**橡胶垫粘贴**:

```
1. 5 mm 厚丁腈橡胶板裁切：弧面长 120 mm，宽 50 mm
2. 沿弧面分 3 段（脚跟/中部/脚趾），降低张应力
3. 表面打磨（240 # 砂纸）增加附着力
4. 502 胶 + 加压 30 秒，静置 24 小时固化
5. 测试摩擦系数：30°斜面静止 → μ ≥ 1.2 合格
```

### 1.4 扭簧定制（最长交期件，建议 2 周前下单）

**膝关节扭簧**:

```
刚度 k = 0.8 N·m/rad
线径 d = 1.2 mm（钢丝）
内径 D = 10 mm
外径 = 12.4 mm
有效圈数 N = 12（参考值，按厂家计算结果为准）
钩端形式：双臂直钩，长度 30 mm，相位 0°
材料：65Mn 弹簧钢，淬火
```

**踝关节扭簧**:

```
刚度 k = 10 N·m/rad
线径 d = 2.5 mm
内径 D = 10 mm
外径 = 15 mm
有效圈数 N = 6
钩端形式：双臂直钩，长度 40 mm
材料：65Mn 弹簧钢，淬火 + 喷丸处理
```

**采购建议**:

- 优先选择「淘宝-定制扭簧店」（搜索关键词：定制扭簧 工业级）
- 询价时提供刚度公差要求 ±10%
- 必须索要刚度测试报告（测扭矩 vs 角度曲线）
- 多备份 2 个（共采购 4 个膝簧 + 4 个踝簧）

**到货验收**:

```
简易刚度测试（无专业设备）:
1. 一端固定，另一端施加已知力臂的砝码
2. 测量旋转角度（用量角器 ±1°）
3. 计算 k_meas = (m × g × L) / θ
4. 与标称值偏差 >15% → 退货重做
```

## 3. 装配步骤详细图解

### 3.1 装配前准备

**工作环境**:

- 平整工作台 ≥120×80 cm，垫防静电橡胶垫
- 良好照明，最好有台灯 + 顶灯
- 通风（焊接和涂胶时）
- 标签贴 + 马克笔（标记每个螺丝包）

**工具清单**:

```
机械工具
  内六角扳手 1.5/2/2.5/3/4/5 mm
  十字螺丝刀 PH00/PH0/PH1
  开口扳手 7/8/10/13 mm
  尖嘴钳、剥线钳、斜口钳
  游标卡尺 0-150 mm
  数显万用表
  电烙铁 60W + 焊锡丝 0.8 mm

测量工具
  电子秤 0.1 g 精度
  量角器或角度尺
  钢直尺 300 mm
  水平仪（手机 App 也可）

化学试剂
  螺丝胶（蓝色 Loctite 243，可拆）
  502 胶
  电气绝缘胶布
  洗板水（清洁焊点）
```

### 3.2 装配步骤 1：单腿组装（左腿示范）

#### 步骤 1.1：髋关节电机准备

```
材料: MX-64AR ×1, MX horn (双臂) ×1, M2.5×8 螺丝 ×4

操作:
1. 拆开电机包装，确认外观无划痕
2. 用 U2D2 + Dynamixel Wizard 测试电机
   - 设置 ID = 1（左髋）
   - 测试转动范围 -180°~+180°
   - 测试堵转扭矩（短时间）
3. 安装双臂 horn 到电机输出轴
   - 对齐 0° 标记（horn 平面与电机外壳长边平行）
   - 用 4 个 M2.5×8 螺丝紧固（点蓝色螺丝胶）
   - 紧固扭矩约 0.5 N·m

完成检查:
  [ ] 电机 ID = 1 已设置
  [ ] horn 与电机轴无明显间隙
  [ ] horn 转动顺滑无卡滞
```

   │         │horn│ ←── 双臂 horn（左右各 25 mm）

#### 步骤 1.2：大腿杆与髋关节连接

```
材料: 大腿杆 ×1, L 型支架 ×2, M4×16 螺丝 ×4, M4 锁母 ×4

操作:
1. 大腿管上端（已钻 2×Φ4.2 孔）对齐 L 型支架
2. 穿入 M4×16 螺栓
3. 加锁紧螺母（不打螺丝胶，便于拆调）
4. L 型支架另一端用 M3×8 螺丝固定到 horn 双臂
5. 紧固扭矩约 1.5 N·m（M4）/ 0.8 N·m（M3）

完成检查:
  [ ] 大腿与 horn 平行（用直尺贴合检查）
  [ ] 大腿可绕电机轴自由转动（电机断电时）
  [ ] 锁紧后无松动（手摇晃测试）
```

#### 步骤 1.3：膝关节组装（含扭簧）

```
材料: MX-64AR ×1 (ID=2), 双臂 horn ×1, 膝扭簧 (k=0.8) ×1
      扭簧固定座 ×2 (3D 打印件), M3×6 螺丝 ×8

操作:
1. 电机 ID 设为 2（左膝），测试同 1.1
2. 一个扭簧固定座（A）粘接在电机外壳侧（用 502 + M3 螺丝双重固定）
3. 另一个固定座（B）固定在 horn 上
4. 装入扭簧：
   - 钩端 1 → 座 A 凹槽
   - 钩端 2 → 座 B 凹槽
   - 关节角度 0°（伸直）时扭簧自然长度
5. 旋转 horn ±10° 检查扭簧回弹力
   - 应感觉到明显回弹力，方向使关节回到 0°
   - 单手转动应需要约 0.1 N·m 力矩

完成检查:
  [ ] 电机 ID = 2
  [ ] 0° 时扭簧无预压（手放开 horn 不动）
  [ ] 弯曲到 70° 时扭簧蓄能 ≈ 0.98 J
  [ ] 反向转动到 -5° 时挡块限位（防反向弯曲）
```

#### 步骤 1.4：小腿杆与膝关节连接

```
材料: 小腿杆 ×1, 短 L 支架 ×2, M3×10 螺丝 ×4

操作: 同步骤 1.2，将小腿连接到膝关节 horn

完成检查:
  [ ] 小腿与 horn 同心，无明显偏移
  [ ] 膝关节弯曲范围实测 0°~70°（手动）
  [ ] 释放后扭簧能自动回到 0°（伸直）
```

#### 步骤 1.5：踝关节组装（被动）

```
材料: 不锈钢轴 Φ8×60 ×1, 608ZZ 轴承 ×2, 踝扭簧 (k=10) ×1
      限位挡块（3D 打印）×2, M3×8 螺丝 ×4

操作:
1. 小腿管下端（已钻 Φ8.1 孔）压入 2 个 608ZZ 轴承
   - 两侧分别压入（小腿管两壁）
   - 轴承外圈与管壁过盈配合（H7/p6）
   - 压入工具：液压千斤顶或夹钳（缓慢加压）
2. 关节轴穿过两个轴承
   - 轴两端各露出 12 mm（用于安装脚底支架）

**hw1_controller.py 框架**:

```python
"""
hw-1 实硬件 FSM 控制器
基于 V13.7（摩擦补偿）+ V17（状态估计）
"""
import time
import numpy as np
from dynamixel_sdk import PortHandler, PacketHandler
from threading import Thread, Lock
import RPi.GPIO as GPIO

# ============ 常量 ============
PORT = '/dev/ttyUSB0'
BAUD = 1000000
PROTOCOL = 2.0
DXL_IDS = {'L_HIP': 1, 'L_KNEE': 2, 'R_HIP': 3, 'R_KNEE': 4}

ADDR_TORQUE_ENABLE = 64
ADDR_GOAL_CURRENT = 102      # MX-64AR 电流模式控制
ADDR_PRESENT_POSITION = 132
ADDR_PRESENT_VELOCITY = 128
ADDR_PRESENT_CURRENT = 126

# V13.7 控制参数
TAU_C_EFF = 0.20  # N·m，库仑摩擦补偿
EPS_SMOOTH = 0.01
TIMESTEP = 0.001  # 1 kHz

class HW1Controller:
    def __init__(self):
        self.ph = PortHandler(PORT)
        self.ph.openPort()
        self.ph.setBaudRate(BAUD)
        self.pa = PacketHandler(PROTOCOL)
        self._setup_motors()
        self._setup_gpio()
        self.fsm_phase = 'stance_early'
        self.lock = Lock()

    def _setup_motors(self):
        for name, dxl_id in DXL_IDS.items():
            # 启用扭矩
            self.pa.write1ByteTxRx(self.ph, dxl_id,
                                    ADDR_TORQUE_ENABLE, 1)
            # 设置工作模式：电流模式（5）
            self.pa.write1ByteTxRx(self.ph, dxl_id, 11, 5)

    def _setup_gpio(self):
        GPIO.setmode(GPIO.BCM)
        GPIO.setup(17, GPIO.IN, pull_up_down=GPIO.PUD_UP)  # 左脚
        GPIO.setup(27, GPIO.IN, pull_up_down=GPIO.PUD_UP)  # 右脚

    def read_state(self):
        """读取所有电机状态"""
        state = {}
        for name, dxl_id in DXL_IDS.items():
            pos, _, _ = self.pa.read4ByteTxRx(self.ph, dxl_id,
                                                ADDR_PRESENT_POSITION)
            vel, _, _ = self.pa.read4ByteTxRx(self.ph, dxl_id,
                                                ADDR_PRESENT_VELOCITY)
            state[name] = {'pos': pos, 'vel': vel}
        # 接触状态
        state['l_contact'] = (GPIO.input(17) == GPIO.LOW)
        state['r_contact'] = (GPIO.input(27) == GPIO.LOW)
        return state

    def compute_fsm_torque(self, state):
        """V13.7 FSM 控制律"""
        # 简化框架，实际从 simulate_v13_7.py 移植
        # 包括：相位判断、PD 控制、能量调节
        tau = {}
        for name in DXL_IDS:
            tau_pd = self._pd_control(state[name], target=0)
            # 摩擦补偿
            omega = state[name]['vel']
            sign_smooth = np.tanh(omega / EPS_SMOOTH)
            tau_comp = TAU_C_EFF * sign_smooth
            tau[name] = np.clip(tau_pd + tau_comp, -4.0, 4.0)
        return tau

    def send_torque(self, tau_dict):
        for name, tau in tau_dict.items():
            dxl_id = DXL_IDS[name]
            # 扭矩转电流：i = tau / Kt
            current_a = tau / 0.058
            # 编码到 -2047 ~ +2047
            current_raw = int(current_a / 4.5 * 2047)
            self.pa.write2ByteTxRx(self.ph, dxl_id,
                                   ADDR_GOAL_CURRENT, current_raw)

    def main_loop(self):
        try:
            while True:
                t0 = time.perf_counter()
                state = self.read_state()
                tau = self.compute_fsm_torque(state)
                self.send_torque(tau)
                # 1 kHz 控制频率
                while time.perf_counter() - t0 < TIMESTEP:
                    pass
        except KeyboardInterrupt:
            self.shutdown()

    def shutdown(self):
        for dxl_id in DXL_IDS.values():
            self.pa.write1ByteTxRx(self.ph, dxl_id,
                                    ADDR_TORQUE_ENABLE, 0)
        self.ph.closePort()
        GPIO.cleanup()

if __name__ == '__main__':
    ctrl = HW1Controller()
    ctrl.main_loop()
```

### 6.3 常见问题与解决方案

#### 问题 1：电机过热

**症状**: 运行 1-2 分钟后电机停转，外壳烫手（>70°C）

**原因分析**:

```
A. 持续大扭矩输出（如低速顶住障碍）
B. 控制增益过高（震荡发热）
C. 通风不良（密闭壳体）
D. 摩擦力过大（机械装配问题）
```

**解决步骤**:

1. 立刻断电散热（>10 分钟，待外壳 <40°C）
2. 检查机械装配：手转动关节应非常顺滑（<0.1 N·m）
3. 降低控制增益（k_PD 从 30 降到 20）
4. 降低 tau_max（从 4.0 降到 3.0）
5. 软件加温度监控（addr 146）：>65°C 自动降扭

#### 问题 2：通信丢包

**症状**: 控制频率不稳定，有时 100 Hz 有时 1000 Hz；状态读取 timeout

**原因分析**:

```
A. 菊花链过长 / 接头松动
B. 波特率与电机不匹配
C. CPU 满载（其他进程占用）
D. USB 线劣质（电源不足或干扰）
```

**解决步骤**:

```python
# 诊断脚本
import time
from dynamixel_sdk import *

success = 0; total = 1000
for _ in range(total):
    t0 = time.perf_counter()
    pos, comm, err = pa.read4ByteTxRx(ph, 1, 132)
    if comm == 0: success += 1

print(f'成功率: {success/total*100:.1f}%')
print(f'平均延迟: {(time.perf_counter()-t0)/total*1000:.2f} ms')

# 期望: >99.9% 成功，<2 ms 延迟
# 不达标的处理：
# - 减少菊花链长度
# - 提高波特率到 3 Mbps（需电机支持）
# - 使用 SYNC_READ 批量读取（减少包数）
```

#### 问题 3：扭矩跟踪误差大

**症状**: 命令 4 N·m，实际只有 2 N·m

**可能原因**:

```
A. 电流-扭矩转换错误（Kt 值不对）
B. 库仑摩擦未补偿（V13.7 算法关键）
C. 电池电压不足（11.1V 标称，<10V 时扭矩损失）
D. 减速箱效率随磨损下降（>50 小时使用）
```

**验证方法**:

```python
# 静态扭矩标定
# 1. 关节悬空，固定 horn 一端
# 2. 在另一端挂砝码（已知力臂 L = 0.05 m）
# 3. 命令 tau = m × g × L
# 4. 测量电机实际承受扭矩（horn 上贴应变片，或用扭矩计）

# 标定结果整理：
#   tau_cmd     tau_meas   误差
#   1.0 N·m    0.85       -15%
#   2.0 N·m    1.78       -11%
#   4.0 N·m    3.62       -10%

# 修正方法：调整 Kt 或加补偿系数
#   tau_cmd_corrected = tau_cmd / 0.9
```

#### 问题 4：接触检测错误

**症状**: 脚底悬空时报告触地，或着地时不报告

**原因分析**:

```
A. 微动开关未正确触发力（阈值 5 N）
B. GPIO 内部上拉/下拉错误配置
C. 走线损坏（关节运动时被拉断）
D. 软件去抖时间过长（>50 ms 错过快速着地）
```

**调试步骤**:

```python
# 实时查看 GPIO 状态
import RPi.GPIO as GPIO
GPIO.setmode(GPIO.BCM)
GPIO.setup(17, GPIO.IN, pull_up_down=GPIO.PUD_UP)
import time
while True:
    print(f"L_contact = {GPIO.input(17)}")
    time.sleep(0.01)
# 用手按压脚底应看到 0/1 切换

# 用万用表蜂鸣档直接测开关
# 若开关本身没问题，检查走线
```

#### 问题 5：电机抖动 / 震荡

**症状**: 关节快速来回振动，发出嗡鸣声

**原因**:

```
A. PD 增益过高（k_PD > 50）
B. 反馈延迟过大（控制频率 < 200 Hz）
C. 编码器零位错误（偏置 >5°）
D. 机械松动（电机 horn 螺丝未紧固）
```

**调优步骤**:

1. 紧急停止
2. 断电后手动转动关节，听有无松动响声
3. 重新标定零位：
   ```python
   # 关节伸直时设为 0°
   pa.write1ByteTxRx(ph, dxl_id, 64, 0)  # 关扭矩
   # 手动调整到目标 0° 位置
   pos, _, _ = pa.read4ByteTxRx(ph, dxl_id, 132)
   pa.write4ByteTxRx(ph, dxl_id, 20, -pos)  # 设置 home offset
   ```
4. 降低增益 50% 后重测，逐步上调

#### 问题 6：跌倒事件

**症状**: 行走 3-5 步后突然失稳

**安全应急**:

```
1. 立刻按急停（红蘑菇头）
2. 检查机器人姿态（卡在导轨上 / 软垫上）
3. 断电 → 手动复位关节角度 → 检查机械有无损坏
4. 查看日志最后 1 秒数据（在 ~/hw1/logs/）
5. 分析故障：
   - 哪个相位失败？（stance_late 还是 swing_thrust）
   - 哪条腿失控？（左还是右）
   - 控制扭矩是否饱和？（tau = ±4.0 N·m）
   - 接触事件是否丢失？
```

**故障复盘表**:

```
| 时间      | 步数 | 失败相位     | 失败原因         | 改进 |
|-----------|------|-------------|------------------|------|
| 第 1 次   | 3    | swing_thrust | E_target 不足    | k_E 7.5→9.0 |
| 第 2 次   | 5    | stance_late | 接触延迟 30 ms   | 加强去抖 |
| ...       |      |             |                  |      |
```
