## 🚀 使用指南

### 快速开始（新用户）
1. 阅读 `QUICKSTART.md`（30 分钟上手）
2. 运行第一个仿真：`tutorials/tutorial_01_run_first_simulation.md`
3. 查看 Dashboard：打开 `dashboard/index.html`

### 日常开发
1. **运行测试**: `.\ci\run_tests.ps1`
2. **代码质量检查**: `.\ci\run_quality.ps1 -Fix`
3. **性能基准**: `.\ci\run_benchmarks.ps1`
4. **完整 CI**: `.\ci\run_all_ci.ps1`

### 参数调优
1. **交互式**: `.\parameter_tuner\run_tuner.ps1`
2. **自动优化**: `python auto_optimization/run_optimization.py`
3. **空间探索**: `python parameter_explorer/example_v137.py`

### 数据分析
1. **查询数据**: `python data_storage/quick_query.py --summary`
2. **分析管道**: `python analysis_pipeline/run_pipeline.py`
3. **跨版本对比**: `python cross_version_analysis/version_comparator.py`

### 学术产出
1. **生成图表**: `python paper_figures/generate_all.py`
2. **查看依赖**: 打开 `version_graph/interactive_graph.html`
3. **编译论文**: `cd publications/paper_draft && pdflatex main.tex`
