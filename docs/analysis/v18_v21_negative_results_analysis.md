**作者**: hw-1 项目组

**版本**: Final

## 执行摘要

V18-V21 构成了 hw-1 项目的**阶段 3：3D 化探索**，历时约 1 个月（2026-06-02 至 2026-06-03），通过三个独立实验系统性地探索了双足机器人侧向稳定的物理边界。虽然所有实验均未达到预期目标（10 次交替/12 秒），但揭示了重要的**理论边界**和**设计准则**，对未来 3D 双足机器人研究具有重要指导意义。

**核心发现**：
1. **侧向被动稳定不存在**（V18）— 矢状面被动与冠状面主动的正交性
2. **单一髋外展执行器不足**（V19）— 侧向漂移修正能力缺口 5-10×
3. **步宽控制复杂度边界**（V20）— 控制律集成未完成，基线不稳定
4. **理性决策**：跳过 V21，回归 2D + 硬件路线（V22-V24）

## 1. 研究问题与假设

### 1.1 初始目标

hw-1 项目在完成阶段 1（V01-V13，2D 步态研究）和阶段 2（V14-V17，2D 机械升级）后，进入阶段 3 的核心问题：

**研究问题**：准被动双足机器人能否在 3D 空间（无侧向约束）实现稳定行走？

**初始假设**：
- H1: 侧向运动可类比矢状面，存在被动稳定极限环（V18 检验）
- H2: 若被动不足，最小主动干预（髋外展 PD）可维持稳定（V19 检验）
- H3: 若单一执行器不足，步宽控制（落脚点规划）可实现稳定（V20 检验）

### 1.2 实验设计原则

1. **渐进式验证**：从被动 → 最小主动 → 完整主动，逐步增加控制复杂度
2. **物理优先**：先验证物理机制，再考虑算法复杂度
3. **定量判据**：成功 = 10 次交替 + 前进距离 > 3 m + 时间 > 12 s
4. **独立性**：三个实验独立设计，互不依赖（允许并行失败）

## 2. 实验结果总结

### 2.1 V18：3D 侧向被动稳定探索

**实验时间**：2026-06-02  
**代码位置**：`v18_3d_lateral_stability/`  

#### 实验设计

**模型修改**：
- V10 准被动模型基础上添加侧向自由度
- hip_y（侧向平移）、hip_roll（滚转）、hip_abd（外展）
- 保持 V10 PD 控制律不变（hip/knee 矢状面）

**测试矩阵**：
- `roll_k` ∈ [0, 50, 100, 200, 500, 1000, 2000] N·m/rad
- 初始扰动：3° 滚转角
- 宽足对照实验：足宽 0.05 m → 0.15 m

#### 定量结果

| roll_k (N·m/rad) | 最大滚转角 (deg) | 失败时间 (s) | 失败模式 | 矢状面影响 |
|------------------|------------------|--------------|----------|------------|
| 0                | 45.2             | 1.2          | 侧向发散 | hip 跌倒   |
| 50               | 12.8             | 2.8          | 侧向发散 | 触发跌倒   |
| 100              | 8.4              | 4.1          | 侧向发散 | 矢状面乱   |
| 200              | 6.3              | 6.7          | 侧向发散 | 步态不稳   |
| **500**          | **4.4**          | **12.0+**    | **刚性约束** | 等效 2D    |
| 1000             | 2.1              | 12.0+        | 刚性约束 | 等效 2D    |
| 2000             | 1.1              | 12.0+        | 刚性约束 | 等效 2D    |

**宽足实验**：
- 足宽 0.15 m（3× 原始）
- roll_k = 100 时最大滚转角 6.3° → 4.4°（微降 30%）
- **仍未改变结论**：无法稳定，只是延缓发散

#### 核心发现

**物理机制**：
1. **roll_k < 200**：侧向被动不稳定
   - 3° 初始扰动 → 躯干滚转发散 → 耦合到矢状面 → hip 跌倒
   - 发散率：~2-3°/秒（线性增长）

2. **roll_k ≥ 500**：刚性约束
   - 等效 2D 导轨（滚转角 < 5°）
   - 失去 3D 行走意义

3. **宽足效果有限**：
   - 仅微降峰值（6.3° → 4.4°）
   - 无法改变稳定域拓扑结构

**Verdict**：`lateral_stability_requires_active_control`

### 2.2 V19：髋外展主动稳定

**实验时间**：2026-06-03  
**代码位置**：`v19_hip_abduction_active/`  

#### 实验设计

**控制策略**（6 种）：
1. **简单 PD**：`τ_abd = k_p × θ_abd + k_d × ω_abd`
2. **hip_y 反馈**：`τ_abd = k_y × hip_y`（位置偏离）
3. **hip_roll 反馈**：`τ_abd = k_roll × θ_roll`（滚转角）
4. **联合反馈**：组合 hip_y + hip_roll
5. **向摇摆侧前倾**：预测性补偿
6. **参数网格**：k_p ∈ [10, 30, 50], k_d ∈ [1, 3, 5]

#### 定量结果

| 策略           | 最佳结果 (alt/s) | 侧向漂移率 (m/step) | 修正能力 (m/step) | 能力缺口 |
|----------------|------------------|---------------------|-------------------|----------|
| 简单 PD        | 3 / 1.2          | 0.08                | 0.008             | **10×**  |
| hip_y 反馈     | 5 / 2.1          | 0.06                | 0.010             | **6×**   |
| hip_roll 反馈  | 4 / 1.7          | 0.07                | 0.009             | **8×**   |
| 联合反馈       | **7 / 2.97**     | **0.05**            | **0.012**         | **5×**   |
| 摇摆侧前倾     | 6 / 2.4          | 0.055               | 0.011             | **5×**   |
| 参数网格       | 7 / 2.85         | 0.052               | 0.011             | **5×**   |

**目标未达**：10 次交替 / 12 秒（最佳仅 7 / 2.97）

#### 核心发现

**物理限制**：
1. **侧向漂移率**：~0.05-0.10 m/step
   - 原因：重力 + 惯性 + 初始条件不对称

2. **abd 扭矩修正能力**：< 0.01 m/step
   - 原因：`τ_abd` 产生躯干倾斜，但**无法直接产生侧向 GRF**
   - 侧向 GRF 需要脚底位移（需要髋 x-y + 膝 + 踝协同）

3. **能力缺口**：5-10×
   - 需要 0.05-0.10 m/step 修正能力
   - 实际仅 0.01 m/step
   - **单一执行器物理上不足**

**Verdict**：`hip_abd_insufficient_for_lateral_stabilization`

### 2.3 V20：步宽控制探索

**实验时间**：2026-06-03  
**代码位置**：`v20_step_width_control/`  

#### 实验设计

**架构**：
- LIPM（线性倒立摆模型）步宽规划器
- 3D IK（inverse kinematics）落脚点调节
- 轨迹规划器（摇摆腿轨迹生成）

**目标**：
- 根据 CoM（质心）侧向速度规划落脚点 y 坐标
- 主动调节步宽以对消侧向漂移

#### 实验状态

**完成部分**：
- ✅ 3D 模型（`model_3d_v20.py`）
- ✅ LIPM 规划器（`step_width_planner.py`）
- ✅ 仿真框架（`simulate_v20.py`）

**未完成部分**：
- ❌ 控制律集成（IK + 轨迹规划器接入仿真循环）
- ❌ 时序同步（规划器更新频率与仿真步长匹配）

**Smoke Test 结果**：
- k_p = k_d = 0（开环测试）
- forward: 0.94 m, sim_time: 1.09 s, alternations: 0
- failure: fall_down（1秒后跌倒）

#### 核心发现

**复杂度低估**：
1. **3D IK 复杂度**：6-DoF（hip x-y-z + knee + ankle x-y）联合求解
2. **轨迹规划**：摇摆腿需要满足 10+ 约束（地面间隙、速度连续性等）
3. **时序同步**：规划器 100 Hz vs 仿真 500 Hz，状态传递延迟

**基线不稳定**：
- V19 基线本身仅 7 次交替
- 在不稳定基线上叠加复杂控制 → 更难调试

**Verdict**：`step_width_control_not_verified`

## 3. 失败机制的深层分析

### 3.1 物理原理层面

#### 矢状面 vs 冠状面的本质区别

| 维度       | 矢状面（前后）| 冠状面（左右）|
|------------|---------------|---------------|
| **重力分量** | 有（沿坡度） | 无（水平面）  |
| **动力学耦合** | 单摆（1阶） | 双摆（2阶）   |
| **被动稳定性** | 存在极限环   | 不存在        |
| **执行器角色** | 补能/稳定   | 必须纠偏      |
| **控制复杂度** | 低（PD/FSM）| 高（IK+规划）|

**为什么矢状面可以被动？**
- 重力提供持续能量输入（下坡分量）
- 碰撞提供瞬时能量重分配（heel-strike map）
- 存在自然吸引子（极限环）

**为什么冠状面不能被动？**
- 水平面无重力分量 → 无能量输入
- 初始扰动线性累积 → 无自然吸引子
- 需要主动纠偏 → 必须有执行器

### 3.2 控制理论层面

#### 可控性分析

**V19 髋外展执行器的物理局限**：

控制输入：`τ_abd`（髋外展扭矩）  
期望输出：`Δy_CoM`（质心侧向位移修正）

**传递路径**：
```
τ_abd → θ_abd → 躯干倾斜 → GRF_y 间接影响 → Δy_CoM
       ↑                      ↑
   单一自由度            需要脚底位移
```

**为什么效率低？**
1. τ_abd 只能倾斜躯干，不能直接移动质心
2. 侧向 GRF 需要脚底相对地面有侧向位移
3. 脚底已接触地面 → abd 扭矩无法产生 net 侧向推力
4. 实际修正能力 < 理论需求的 20%（0.01 vs 0.05 m/step）

**V20 步宽控制的可控性**：

理论上可行：
- 摇摆腿可主动调整落脚点 y 坐标
- 直接控制支撑多边形几何 → 直接影响 CoM 稳定性

实践困难：
- 需要 6-DoF IK 实时求解（计算复杂度）
- 轨迹规划需满足多约束（地面间隙、速度连续性、碰撞避免）
- 状态估计需要高精度（CoM 速度估计误差 → 规划错误）

### 3.3 设计空间边界

#### 三次否定实验的互补性

```
                    侧向稳定设计空间
                          ↓
        ┌─────────────────────────────────┐
        │                                 │
        │  V18: 被动不存在 ✗              │
        │        ↓                        │
        │  V19: 单执行器不足 ✗            │
        │        ↓                        │
        │  V20: 多执行器+规划未验证 ✗     │
        │                                 │
        └─────────────────────────────────┘
                          ↓
              结论：3D 需要复杂主动控制
                   （超出本项目范围）
```

**设计准则**：
1. **矢状面可被动，冠状面需主动** — 正交性原理
2. **单一髋外展执行器不足** — 物理极限（5-10× 缺口）
3. **步宽控制复杂度高** — 需要完整 3D IK + 状态估计 + 轨迹规划
4. **2D + 导轨约束是当前最优解** — 在预算和时间约束下

## 4. 学术价值与贡献

### 4.1 理论贡献

#### 正交性原理（Orthogonality Principle）

**命题**：对于类人双足机器人，矢状面动力学与冠状面动力学在被动稳定性上呈现**正交性**。

**证据**：
- 矢状面：V05 证明纯被动极限环存在（λ_max = 0.944）
- 冠状面：V18 证明被动稳定不存在（roll_k < 200 → 发散）

**工程意义**：
- 设计 3D 双足机器人时，不能简单类比 2D 成功经验
- 必须为冠状面设计**独立的主动稳定系统**

#### 执行器能力边界（Actuator Capability Boundary）

**命题**：单一髋外展执行器的侧向修正能力存在**物理上界**（~0.01 m/step），无法对消典型侧向漂移率（~0.05 m/step）。

**量化结果**：
- 漂移率：0.05-0.10 m/step
- 修正能力：< 0.01 m/step
- 缺口：5-10×

**设计指导**：
- 侧向稳定需要**多执行器协同**（hip x-y + knee + ankle）
- 或需要**落脚点规划**（步宽控制）
- 单一 abd 关节不足以作为唯一侧向稳定机制

### 4.2 方法论贡献

#### 渐进式否定验证（Progressive Falsification）

**方法**：
1. 提出由简到繁的假设链（被动 → 最小主动 → 完整主动）
2. 逐级验证，每级失败提供下一级的设计约束
3. 三次独立否定 → 明确设计空间边界

**优势**：
- 系统性覆盖设计空间
- 否定结果也提供价值（排除不可行区域）
- 为决策提供量化证据

**应用价值**：
- 避免盲目尝试复杂方案
- 提供"何时止损"的理性判据
- 适合资源受限的研究项目

#### 决策门方法论（Decision Gate Methodology）

**V20 后的决策逻辑**：

```
输入：V18 + V19 + V20 三次否定结果
约束：预算 < 10k 元，时间 < 3 个月

决策树：
├─ 选项 A：继续 V21（3D 扰动鲁棒性）
│  └─ 预期：即使验证成功，仍需复杂控制律 → 硬件成本翻倍
│
├─ 选项 B：跳过 V21，转向 2D + 硬件（V22-V24）
│  └─ 优势：否定结果已充分，2D 技术成熟，硬件可制造
│
决策：选择 B
理由：
  1. 三次否定已明确 3D 需要复杂主动控制
  2. 复杂控制超出本项目技术储备和时间预算
  3. 2D 主线（V13.7 + V17）已成熟，可直接落地
  4. 3D 留作未来工作，在硬件平台上实测驱动算法设计
```

**学术价值**：
- 透明化决策过程（可复现、可批判）
- 为类似项目提供决策参考
- 体现**理性止损**而非盲目追求

## 6. 对未来工作的启示

### 6.1 技术路线建议

#### 对于准被动双足机器人

**推荐架构**：
- **矢状面**：准被动（FSM + 摩擦补偿，V13.7 已验证）
- **冠状面**：主动稳定（最小配置：hip abd + 落脚点规划）

**不推荐**：
- ❌ 完全被动 3D 行走（V18 证明不存在）
- ❌ 单一髋外展执行器（V19 证明不足）

#### 对于完全主动双足机器人

**必要组件**：
1. **3D IK**：实时逆运动学求解器
2. **状态估计**：CoM 位置/速度估计（误差 < 5%）
3. **轨迹规划**：摇摆腿轨迹生成（满足 10+ 约束）
4. **落脚点规划**：LIPM 或 MPC
5. **多执行器协同**：hip x-y + knee + ankle

### 6.2 硬件设计指导

#### V22 2D 样机的战略意义

**为什么先做 2D？**
1. **技术成熟度**：V13.7 + V17 已闭环验证
2. **成本可控**：6500-8000 元（vs 3D 的 13000+ 元）
3. **制造周期短**：2-3 个月（vs 3D 的 6+ 个月）
4. **验证价值高**：
   - 验证 sim-to-real gap
   - 积累硬件调试经验
   - 为 3D 提供传感器/执行器选型数据

**3D 作为未来工作**：
- 在 2D 硬件平台上验证控制算法
- 用实测数据驱动 3D 算法设计（避免 V20 的盲目复杂化）
- 分阶段：先实现侧向主动稳定（hip abd），再扩展到步宽控制
