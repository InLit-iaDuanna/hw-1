# V14 被动摆臂版（passive arms）

## 一句话定位

在 V10 滚动足准被动模型上挂两根**纯被动摆臂**（hinge + 惯性 + 阻尼，**无 actuator**），考察机构变化对 V10 控制律的扰动效应——直接对接 V13 决策门关于"V10 控制律是 (kp, kd) 平面孤立点解"的预警。

## 学术档位

**准被动**（与 V08–V11 同档）。摆臂本身被动，但 hip + knee 仍主动 PD 控制，**不可宣称纯被动**。

## 关键结果

扫描 (arm_mass × arm_length) = 7 × 5 = 35 点，每点 12 s，控制律继承自 V10 best (`hip_kp=30, hip_kd=6, gait_period=0.80`)。

| 摆臂质量 / kg | 0.001 | 0.05 | 0.10 | 0.20 | 0.30 | 0.45 | 0.60 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 成功 / 5 | **5** | 0 | 0 | 0 | 0 | 0 | 0 |
| 主要失败 | — | fall | fall | fall | stuck | stuck | mix |

整体成功率 **5/35 = 14.3%**，且**全部成功**集中在 `arm_mass=0.001` 的"无臂退化"行；任何真实摆臂质量（≥0.05 kg）都让 V10 控制律失稳。

**长度（0.20–0.60 m）几乎无影响**——质量是主导轴。

## 解读

这是 V13 决策门 §3.1 「V10 是 (kp, kd) 孤立点解，机构改动会推离工作点」的**直接实验验证**。本版本**不是要在 V10 控制律上找到一个能走路的摆臂版**——这与 V13.5 控制律重设计的目标重叠；本版本作用是**为决策门补一份独立机构维度证据**：

1. 几何参数（V13 §2.1）：foot/leg 切片只有 ≤17% 成功率
2. 控制律参数（V13 §2.2）：(kp, kd) 平面孤立点 + 共振线
3. **机构追加**（V14，本版）：摆臂质量 ≥0.05 kg 即破坏稳定 → 三维证据闭环

## 后续路径

V14 的"基线"行（arm_mass=0.001）等价于 V10，无新意；任何能展示**摆臂动态解耦**价值的版本必须在 V13.5 控制律重设计完成后回流：

- **V14b**（待 V13.5 完成后）：用 V13.5 鲁棒控制律重跑同一扫描，预期成功率应显著提升，否则连续盆地假设也站不住
- **V14 与 V15 / V16 顺序**：在 V13.5 完成前不建议继续推进 ROADMAP V15+，否则每版都会重复"机构改动 → 落出孤立点 → 失败"

## 学术诚信口径

- "V14 摆臂版能行走" 必须**带 arm_mass ≤ 0.001 kg 前提**写出（即等价于 V10），否则失实。
- "成功率 14.3%" 不可改写为"找到了可行参数族"——所有成功都集中在退化行。
- 失败模式分裂（fall vs stuck）按摆臂质量带书写，不要混淆。
- 本版本**不证明被动摆臂动力学耦合机制无效**，只证明 V10 控制律不能容纳它。
