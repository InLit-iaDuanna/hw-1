# V13.5 方案 C：能量整形 bang-bang hip 控制器（被否决）

**状态**：方案 C 与 A、A' 一样被实验数据否决。本文件记录设计、实验、结论。

**日期**：2026-05-27

## 1. 设计

### 1.1 动机

V13.5 lessons §4 已经证明：V10 hip 控制律是 bang-bang 隐式饱和供能脉冲（force saturation 占空比 ≈ 58.8%），而非 PD 角度跟踪。方案 A（自适应步周期）和方案 A'（提力矩限幅）失败的根因都是把"开关式注入"误读为"线性反馈"。

方案 C 的逻辑：既然 V10 的本质是 bang-bang 能量注入，那就**直接显式建模**这个过程，期望得到一个比 V10 更鲁棒的参数族（而不是孤立点）。

### 1.2 公式

每个 timestep：

```
E_current = 0.5 * m_eff * (vx² + vz²) + m_eff * g * z       # 整机平动能量
m_eff     = hip_mass + 2 * torso_mass = 5.1 kg               # 与 V13b E* 同口径
e_E       = E_star - E_current                               # 能量误差
A         = clip(k_E * e_E, 0, hip_torque_limit)             # 推力幅值；e_E ≤ 0 不推
sgn       = sign(swing_target - q_hip)                       # 沿 PD 误差方向
hip_tau   = A * sgn                                          # bang-bang 推力
```

knee 控制保留 V10 PD（V13 切片显示 knee 不是孤立点的主因）。stance / swing 角度 reference 沿用 V10 的相位插值（smoothstep 平滑过渡）。

### 1.3 参数

| 参数 | 默认值 | 来源 |
|---|---|---|
| `E_star` | 52.66 J | V13b Floquet 长程辨识（n=19 步，duration=20 s） |
| `k_E` | 7.5 Nm/J | ≈ τ_lim / E_std = 4 / 0.53，使 \|e_E\|≥0.5 J 时推力立即饱和 |
| `hip_torque_limit` | 4.0 Nm | 与 V10 / V13b 一致，保留为硬上限 |
| `E_dead` | 0 J | 死区（保留接口，默认关闭） |

### 1.4 与方案 A / A' 的本质区别

| | 方案 A | 方案 A' | 方案 C |
|---|---|---|---|
| 设计入口 | 相位（time → u）| 力矩限幅 | 能量（E* → A）|
| hip 力矩计算 | PD 跟踪 + 饱和 | PD 跟踪（不饱和）| 能量误差 → bang-bang |
| 是否仍依赖 hip_kp/kd | 是 | 是 | 否（仅符号）|
| 与 V10 关系 | 改相位，保 PD | 取消饱和，保 PD | 取消 PD，保留饱和 + 显式能量 |

## 2. 实验

### 2.1 Baseline（V10 几何 + plan C 控制律）

`simulate_v13_5_planC.py --duration 12.0`：

| 指标 | V10 baseline | plan C baseline |
|---|---|---|
| success | True (12 步) | False（9 步触地，差 1 步）|
| forward_distance | 4.56 m | 4.04 m |
| simulated_time | 11.99 s | 11.99 s（不摔倒、未停止）|
| failure | completed | completed（达到 duration 上限）|
| mean \|e_E\| | — | **0.19 J**（< E_std=0.53，能量目标确实锁住）|
| hip 主动占空比 | 58.8% | **85.2%** |

**观察**：plan C 的 baseline **没摔**，能量误差 0.19 J，但触地节奏比 V10 慢 25%，最终 12 s 内只走出 9 步（V10 12 步）。能量目标锁得住，但步态频率被打散——这是 bang-bang 推力**符号不带相位锁定**导致的。

### 2.2 切片 C：foot_radius × leg_scale 6×6（主交付）

V13 切片 C（V10 控制律）成功率：**6/36 = 16.7%**。

plan C 在同一栅格上：

| | plan C |
|---|---|
| 成功格 | **0/36 = 0.0%** |
| Δ vs V10 | **−16.7 pp** |

关键观察（来自 `out/v13_5_planC_C_foot_leg.csv`）：

- 短腿格（leg_scale ≤ 0.98）：`mean\|e_E\| ∈ [7, 13] J`，duty=100%——能量永远追不上 E*，但因短腿天然能量低，推力不停饱和却仍跌倒（td=1）。
- 中等腿（leg_scale ≈ 1.02）：`mean\|e_E\| ≈ 0.4 J`，duty 30% 左右——能量跟踪好，但只走 2-7 步就摔。
- 长腿（leg_scale ≥ 1.06）：能量盈余，duty 0-50%，仍是 1-9 步摔。
- V10 在 (0.034, 0.90) / (0.038, 0.90) / (0.038, 0.94) / (0.038, 0.98) / (0.046, 1.06) / (0.046, 1.10) 这 6 个格子上成功，plan C **无一保住**。

### 2.3 切片 kE_Estar：k_E × E_star 6×6（副产品）

baseline 几何下扫 plan C 自身参数：**0/36 = 0%**。

观察：

- E_star ≥ 53.6 J（高于 V13b 测得的 52.66 + 1σ）：所有 k_E 都 duty=100% 仍摔——目标过高，永推不停。
- E_star ≤ 51.2 J（低于 V13b 测得 1σ）：duty 60-90%，但 1-4 步摔——目标过低导致欠驱动。
- E_star = 52.4 J 附近：能走 3-5 步，但没有任何格子达 10 步成功线。

**结论**：plan C 在自身参数空间里也找不到一个稳定盆地，不是"调参不对"而是控制律本身缺东西。

## 3. 失败机理分析

V10 bang-bang 之所以稳，是因为饱和的**触发条件 = 角度误差**（所以推的是"该推的腿"），而饱和的**释放时机 = PD 平衡**（推到目标位置自然停）。这两个时机都被**步周期相位**和**接触切换**自然同步，构成了"准被动 + 隐式同步"的极限环。

plan C 把幅值的决定权交给"整机能量"，但：

1. **能量是慢变量**——一步触地后能量立刻 dump 1-2 J（碰撞损失），bang-bang 反应过慢。
2. **能量不区分腿**——左右腿都看到同一个 e_E，符号只由 PD 残差决定，但 PD 残差在 stance 末期接近 0，导致符号抖动 / 同时双腿推力（baseline duty=85% 远大于 V10 的 59%，说明推力在 stance 也没停）。
3. **缺乏触地相位锁定**——V10 的 burst_start_t 重置 + smoothstep 让推力轨迹与触地事件对齐；plan C 的能量推力没有这个时间锚定，幅值波形与步周期解耦。

结果：plan C 只把 E_current 的均值锁在 E* 附近（baseline mean|e_E|=0.19 J 漂亮），但**步态时序结构被破坏**，触地节奏从 V10 的 12 步降到 9 步，再加上几何扰动后立即崩溃。

## 4. 学术诚信口径

- **不能写**"方案 C 实现了能量整形 bang-bang 鲁棒控制器并扩大盆地"——数据反例 0/36。
- 可以写：
  - "方案 C 能锁住整机机械能均值在 E* ± 0.2 J（baseline 验证），但能量稳态不等于步态稳态。"
  - "V13.5 三个方案（A: 相位前馈，A': 提力矩限幅，C: 能量整形 bang-bang）均被实验否决。共同教训：**V10 极限环的稳定性来自 hip 力矩与触地相位的隐式锁定，单一标量目标（角度 / 力矩饱和点 / 整机能量）都不足以替代这个时序耦合**。"
- plan C 仍属准被动（hip 主动，但目标是能量而非位置）；这一点对未来报告口径有正面价值——确认了方案 C **方向正确但模型不够**。
