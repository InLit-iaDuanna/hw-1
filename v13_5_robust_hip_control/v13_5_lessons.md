# V13.5 控制律重设计 — 教训记录

**状态**：方案 A、A'、C 三种均被实验否决。本目录归档全部负面发现，决议见 §10。

**日期**：2026-05-27（决策门触发于 2026-05-26）

## 1. 启动动机

V13 决策门（`v13_parameter_sensitivity_atlas/v13_decision_gate.md`）发现 V10 hip 控制律在 (kp, kd) 平面是孤立点 + 共振线（F 切片反例），不是连续盆地。判断：阶段 2（V14-V17）任何机构改动都会把工作点推离孤立点，必须先把 hip 控制律从"点解"扩成"参数族"。

## 2. 方案 A：步周期前馈 + PD（被否决）

**假设**：V10 用静态 `gait_period` 算相位 `u = (t - burst_start_t) / gait_period`，相位错位是孤立点的根因。

**实现**：`simulate_v13_5.py`，每次接受新接触事件时用 EMA 更新 `T_meas`，前馈到相位计算，其余 V10 helper 全部复用。

**结果（baseline kp=30, kd=6）**：

| alpha | 触地数 | 距离 | 失败 |
|---:|---:|---:|---|
| 0.0（退化为 V10）| 12 | 4.56 | completed ✓ |
| 0.1 | — | — | fall_down |
| 0.2 | — | — | fall_down |
| 0.4 | 4 | 1.33 | fall_down |

**结果（V10 失败点 F(0,2) kp=15, kd=2.7）**：alpha 全档 0.0–0.8 均 fall_down，6 步左右倒。

**否决依据**：T_meas 调整本身扰乱了已经 lock-in 的极限环；周期 EMA 跟不上单步剧烈变化（步周期在 0.40–0.63 抖动），方向无效。

## 3. 方案 A'：提高 hip_torque_limit（被否决，**反直觉**）

**修正假设**（基于方案 A 的 period_history）：根因不是相位是 PD 饱和，τ_limit=4 太低，提高后 kp 容差应变宽。

**实现**：V13 atlas 新增切片 G `hip_kp × hip_torque_limit`，固定 ratio=0.20，6×6 = 36 点。

**结果**：

| τ_limit | 成功 / 6（kp ∈ [15, 45]）|
|---:|---:|
| 4.0 | **4**（kp 27/33/39/45） |
| 7.2 | 0 |
| 10.4 | 0 |
| 13.6 | 0 |
| 16.8 | 0 |
| 20.0 | 0 |

**完全反直觉**：力矩限幅一旦提高，原本成功的 kp 也全部摔。

## 4. 修正后的机理

A' 失败迫使重新建模 V10 hip 控制律。`diagnose_saturation.py` 量化了三条 replay 轨迹：

| Tag | 成功 | sat% (\|τ\|≥0.95·τ_lim) | mean\|τ\|/τ_lim |
|---|---|---:|---:|
| baseline | ✓ 12 | **58.8%** | 49.0% |
| C_foot_leg(0,0) stuck | ✗ 4 | 42.6% | 61.0% |
| F_kp_ratio(0,2) fall | ✗ 6 | 60.1% | 62.1% |

**关键观察**：

1. baseline 成功时力矩 **过半时间在饱和** → V10 不是 PD 跟踪，而是**间歇性饱和供能**。
2. F 失败案例 sat% 几乎一样（60.1%）但 mean|τ|/τ_lim 反而高（62%）——**力矩长时间停在饱和与释放之间**，既没推够也没让够。
3. 提高 τ_limit（A'）后 PD 完全不饱和 → 永远是平滑跟踪 → 缺少 V10 极限环需要的开关式能量注入 → 全摔。

**机理结论**：V10 的"准被动稳定行走"实际上是 **bang-bang 隐式饱和驱动**，PD 增益本质上是**饱和占空比的形状参数**而非线性反馈增益。这解释：

- 为什么 (kp, kd) 是孤立点：饱和占空比对增益高度非线性。
- 为什么 V13 切片成功带极窄：任何改动只要让占空比偏离 ~58%，极限环就破。
- 为什么"更好的 PD"（A 自适应、A' 解饱和）反而更糟：朝错误方向（更平滑跟踪）走。

## 9. 方案 C 实验日志（能量整形 bang-bang）

**假设**：V10 hip 是 bang-bang 隐式饱和供能脉冲；显式建模 = 用整机机械能 E* 决定推力幅值，应得到比 V10 更宽的稳定盆地。

**实现**：`simulate_v13_5_planC.py` + `scan_planC_v13_5.py`。

```
e_E = E_star - E_current;  hip_amp = clip(k_E * e_E, 0, τ_lim);  hip_tau = hip_amp * sign(swing PD)
```

`E_star = 52.66 J`（V13b Floquet 测得，duration=20 s, n=19）；`k_E = 7.5 Nm/J`；knee 保 V10 PD。

### 9.1 Baseline（V10 几何）

| 指标 | V10 | plan C |
|---|---|---|
| success | True (12 步) | **False（9 步，差 1 步触地阈值）** |
| forward_distance | 4.56 m | 4.04 m |
| failure | completed | completed（未摔，到达 duration）|
| mean \|e_E\| | — | 0.19 J |
| hip 主动占空比 | 58.8% | **85.2%** |

能量目标确实锁住（误差远小于 1σ=0.53 J），但步态频率被压缩、占空比反而上升。

### 9.2 切片 C：foot_radius × leg_scale 6×6（与 V13 同栅格直接对比）

**plan C 成功率：0/36 = 0.0%**（V10 = 6/36 = 16.7%，**Δ = −16.7 pp**）。

V10 在 (0.034, 0.90) / (0.038, 0.90/0.94/0.98) / (0.046, 1.06/1.10) 这 6 格成功；plan C **无一保住**，全部 1-9 步内失败。

短腿格 e_E 长期 7-13 J，duty=100%（推力永远饱和但能量仍追不上）；中腿格 e_E ≈ 0.4 J（能量跟踪好）但仍摔——证明能量稳态 ≠ 步态稳态。

### 9.3 切片 kE_Estar：k_E × E_star 6×6（副产品）

baseline 几何下扫 plan C 自身参数：**0/36 = 0%**。E_star ≥ 53.6 J 全部 duty=100% 仍摔（目标过高），E_star ≤ 51.2 J 欠驱动 1-4 步摔，最佳点 E_star=52.4 J 也只走 3-5 步。**plan C 在自身参数空间里也找不到稳定盆地**。

### 9.4 失败机理（事后分析）

V10 bang-bang 的稳定性来自**触发条件 = 角度误差**（推该推的腿）+ **释放时机 = 接触切换 + smoothstep 相位**（自然同步）。plan C 把幅值决定权交给整机能量，但：

1. 能量是慢变量，碰撞 1-2 J 跳变后 bang-bang 反应过慢；
2. e_E 不区分左右腿，符号由 swing PD 残差决定但 stance 末期残差 ≈ 0，导致双腿同时推（duty=85% > V10 的 59%）；
3. 能量推力没有 burst_start_t 锚定，幅值波形与步周期解耦——**步态时序结构被破坏**。

## 10. 最终决议（V13.5 闭环 + V14 路线选择）

### 10.1 V13.5 三方案统一否决

| 方案 | 假设 | 切片 C 成功率 | 否决依据 |
|---|---|---:|---|
| A 步周期前馈 | 相位错位是孤立点根因 | n/a（baseline 即摔）| period_history 抖动 0.40-0.63 s，EMA 跟不上 |
| A' 提力矩限幅 | 饱和 = bug，应解饱和 | 4/36（仅原成功带的 kp=27/33/39/45）| τ_lim>4 后 PD 不再饱和 → 能量注入消失 → 全摔 |
| **C 能量整形 bang-bang** | **显式 E* 比隐式饱和鲁棒** | **0/36（vs V10 6/36）**| **能量锁住但步态时序破坏，反而比 V10 还差 −16.7 pp** |

**统一教训**：V10 极限环的稳定性 = hip 力矩 ⊗ 触地相位 的**隐式时序锁定**。任何"单一标量目标"（位置 / 力矩饱和点 / 整机能量）都把这个二维耦合压成一维，必然丢失稳定信息。

### 10.2 V14 路线选择

**推迟 V14 的"机构改动 + V10 控制律"原计划**（依据：plan C 的 0/36 已经证明孤立点根因不在控制器形式，而在控制器与触地事件的时序绑定方式）。

V14 的正确切入点：**事件驱动状态机 hip 控制律**。每次 stable_contact 切换时进入新 phase，phase 内的力矩由"当前 phase + 当前能量"二维查表决定，使时序锁定从隐式变显式。具体来说：

- 状态：`{stance_early, stance_late, swing_thrust, swing_retract}`，由触地事件 + clearance + 相位 u 触发。
- 每态独立的 (k_E, k_PD, τ_max) 三元组，可以独立调参。
- 相当于把 V10 隐式 bang-bang **解构成 4 段显式 bang-bang**，每段都有自己的目标（能量 / 角度 / 时机）。

如果连这个都失败，再回到模仿学习 / RL 路线（用 V10 的 baseline 轨迹做监督，绕开手工控制律）。

### 10.3 不再做的方向

- 任何"全局 PD"调参（E/F/G 三切片 + A/A'/C 三方案已系统排除）；
- LQR 围绕极限环线性化（与 bang-bang 本质冲突）；
- 单纯改 E_star / k_E（kE_Estar 切片 0/36 已排除）。

### 10.4 V13.6 实测回流（2026-05-28）

§10.2 提出的"事件驱动 FSM"路线已作为 **V13.6**（`../v13_6_event_driven_fsm/`）实现并测试。

**实现要点**（不改本节原内容，仅补结果）：

- 状态集合按 §10.2 一致：`{stance_early, stance_late, swing_thrust, swing_retract}`。
- 每 phase 独立的 (k_E, k_PD, τ_max, kd) 三元组（暴露给康复设备调参接口）。
- **修订点**：phase target 角度 *不* phase-local。最初 phase-local 目标导致切换时刻的角度阶跃破坏 V10 的 smoothstep 时序锁定（baseline 即摔）。改为：phase 只控制"力如何作用"，目标轨迹沿用 V10 全局 smoothstep——与临床直觉一致（医生调节"该相位用多大力"，目标轨迹不分段）。
- swing_thrust phase 沿用 plan C 的能量整形 (k_E·max(0, E*−E)) 形式，但 **只在该 phase 激活**，其余 phase 纯 PD——绕开 plan C 的"双腿同时推 + 步态时序解耦"问题。

**切片 C 复扫结果（与 V13 / plan C 同栅格 6×6 = 36 点）**：

| 控制器 | success / 36 | rate | Δ vs V10 |
|---|---:|---:|---:|
| V10 baseline PD | 6 | 16.7% | — |
| plan C 能量整形 bang-bang | 0 | 0.0% | −16.7 pp |
| **V13.6 事件驱动 FSM** | **4** | **11.1%** | **−5.6 pp** |

**结论**：

1. FSM 路线**部分有效**（11.1% > plan C 的 0%，证明 §10.2 的判断正确），但**未恢复**到 V10 水平。
2. 成功格分布**不重合**：V10 在 (0.034/0.038, 短腿) 与 (0.046, 长腿) 对角带；V13.6 在中央 (0.038–0.042, 1.0±) 方块区。FSM 切到了**另一个邻近极限环**，不是简单复刻 V10。
3. baseline 通过（11 td / 4.86 m / CoT 0.072）+ 切片 11.1%，归为 **tier B**："路线正确但参数未调优"。
4. 下一步：V13.6.1 在每 phase 上独立 grid search 拓宽，目标恢复到 ≥17%。若仍卡在 11–14%，再走 V13.7 模仿学习。
5. 学术诚信修订：原 §8 建议的版本表一行"V13.5 否决，确立 V14 = 事件驱动 FSM"应理解为"V13.6 实施该路线，部分有效未达 V10"——不能宣称 FSM 是"鲁棒控制器"。

## 11. V13.6.1 + V14b 实测回流（2026-05-28）

V13.6.1 phase 参数搜索得 best cand 6（仅 `swing_retract_tau_max` 2.0→3.0，其余沿用 V13.6 原值；`swing_thrust_k_E=7.5, swing_thrust_k_PD=10.0, swing_thrust_tau_max=4.0, stance_late_tau_max=4.0`）。同期 V14b（FSM hip + 被动摆臂）完成摆臂参数空间扫描与切片 C 复扫。综合两组实验抽出两条跨版本 lesson。

### 11.1 Lesson A：FSM 参数搜索能挽回无摆臂下的几何容差，与摆臂耦合后增益归零

**Why**：V13.6.1 best 把切片 C 从 11.1%（V13.6 原参数）抬到 13.9%（无摆臂）；但 V14b + V13.6.1 best 仍是 3/36=8.3%，与 V14b + V13.6 原参数下完全相同，成功域是 V13.6.1 无摆臂域的严格子集。也就是说 phase 调参在无摆臂几何上拿到的 +2.8 pp 增益，被摆臂自由度耦合后清零。

**How to apply**：阶段 2 中若某个机构改动（摆臂、SEA、电机）导致几何边缘失稳，优先改机构（V14c 摆臂力学 / 阻尼 / 锁定）而不是再调 FSM 参数；FSM 调参对"机构耦合产生的失稳"无解，再多 grid search 也只是 in-distribution 的过拟合。

### 11.2 Lesson B：phase-locked FSM 对扰动鲁棒，对几何容差不鲁棒；与 V10 PD 互补

**Why**：V13.6.1 best 在切片 A（slope_deg × foot_radius，坡度扰动维度）4/36=11.1%，+8.3 pp vs V10 PD（1/36=2.8%）；同一控制器在切片 C（foot_radius × leg_scale，几何容差维度）5/36=13.9%，-2.8 pp vs V10 PD（6/36=16.7%）。这是 phase-locked FSM 的结构特征：时序锁相对外扰天然鲁棒（坡度变化不破坏 phase 切换条件），但不会扩大极限环存在边界（几何参数移动了极限环本身，FSM 跟不上）。

**How to apply**：选择控制 baseline 时按场景分：
- 坡度 / 扰动相关的升级（V15 SEA, V17 传感器, V21 3D 扰动）→ 用 V13.6.1 best；
- 几何容差相关的对比（V14/V14b/V14c 机构维度, V22 硬件公差）→ 保留 V10 PD 作为对照不能丢。

V13.6.1 与 V10 不是替代关系，而是覆盖不同失稳方向的两个 baseline，论文中应并列报告。
